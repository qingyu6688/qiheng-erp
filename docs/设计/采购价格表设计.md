# 采购价格表设计

状态：6项专项业务、500行容量、真实浏览器取价及常规回归证据通过，尚未发布。对应 B-07，新增迁移 V112已执行并冻结，范围及限制见《测试报告》。

现有 `price_list`、`price_list_item` 的有效期、优先级、单位和数量阶梯继续使用；`price_list_target` 新增 `supplier`。供应商价格表只接受供应商目标，销售价格表禁止供应商目标。列表、读取及更新均按目标类型隔离，不允许通过销售价格表路径访问采购价格。

新增采购价格表维护入口、查看和维护权限，并要求成本查看权限。采购订单默认价格依次取有效供应商协议价、同公司同供应商最近已批准采购价、SKU参考采购价。协议按优先级、数量阶梯、价格表ID确定；历史价按采购业务日期、批准时间、行ID确定，并遵守当前组织与仓库范围。

价格响应区分实际录入来源、建议价来源、所用价格表及版本、历史采购行、税口径和协议超价情况。订单行保存取价快照，审批后沿用原快照，不因价格表维护改写历史订单。手填价可用，价格高于协议时默认提示，公司参数可设为必须审批；该模式需另一名可查看成本的采购审批人，未绑定流程时仍须安装默认人工流程。

实现顺序：迁移与价格表隔离、批量取价、订单快照及审批约束、采购价格表和订单右侧页面。所有步骤完成后进入 B-08，测试统一放到全部剩余功能实现后，按模块逐步执行。此文不作为验证通过证据。
