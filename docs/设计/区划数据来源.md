# 区划数据来源

本轮采用民政部公开的[2024年中华人民共和国县以上行政区划代码表](https://www.mca.gov.cn/mzsj/xzqh/2025/202401xzqh.html)，由2025年发布的官方表转换为V40迁移，下载核验日期2026-11-16。迁移头保留原始HTML的SHA-256，原始文件仅留在私有验收目录。

原详细设计使用“国家统计局代码”的表述；实际改用可直接核验的民政部县级以上官方行政代码，保存六位数字代码和官方名称，不编造最新区划。数据版本显示为MCA-2024，后续官方调整通过新增迁移更新，旧地址原文和历史代码继续保留。

直辖市及省直辖县级单位在官方表没有中间市级代码时，直接挂到省级节点，不虚构“市辖区”代码。台湾、香港及澳门按照官方表提供的省级节点保留，不补造未公开的下级代码。树选择允许直接选择已有层级，原文本地址保留。

本数据用于业务地址选择，不作为行政事项办理或实时行政区划证明。文档维护：maorongkang@gmail.com。
