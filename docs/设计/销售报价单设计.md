# 销售报价单设计

状态：8项专项业务、500行容量、真实浏览器转单及右侧来源、规则切换拦截及常规回归证据通过，尚未发布。对应 B-08，新增迁移 V113已执行并冻结，范围及限制见《测试报告》。

## 业务及状态

报价记录客户、业务日期、有效期、价格口径、明细及可选商机。报价不预占库存，也不确认应收或信用占用。正常价格确认后生效；最低价按当前公司已有提示、审批、禁止规则控制，低价需审批时沿用现有人工价格复核权限和快照校验。禁止策略拒绝保存和生效。

状态为草稿、审批中、有效、已驳回、已转单、已失效、已作废。有效期包括截止日当天，按北京时间判断；自动到期保留全部事实。到期的在途审批同步结束，不能出现页面已失效而后台继续通过的报价。

## 转销售订单

须同时有报价转单及销售订单创建权限；仅有效且未过期报价可转单。一张报价只能对应一张销售订单，报价头和转单记录在同一本地事务内锁定。转单冻结已确认的商品、单位、价格、税率、优惠及费用，生成订单草稿后关闭报价。订单继续独立进行库存、信用及最低价复核，不跳过正式订单流程。

## 数据与权限

`sales_quote`保存表头、报价输入与计价快照、最低售价依据、工作流和转单关联；`sales_quote_line`保存计价明细和最低价快照。采用独立的查看、创建、修改、提交、审批、转单、作废权限；同时检查当前公司、实际仓库、组织及关联商机范围。销售订单保留`sales_quote`来源，原报价及审计不回写为订单事实。

## 页面与验证安排

销售菜单增加报价列表，创建、修改、查看、价格与有效期摘要、商机选择和转单均使用右侧抽屉。转单后显示订单草稿编号，查看订单仍在右侧打开。未知结果保留原参数和请求键。

功能代码及文档完成后，统一按模块验证正常报价、低价提示/审批/禁止、价格快照变化、到期及审批结束、转单原子性、重复请求、权限收窄、右侧详情与完整业务回归。本设计不表示功能或验证已经完成。
