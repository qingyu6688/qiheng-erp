# 采购费用分摊设计

版本：1.0.0，2026-11-23。状态：B-03 已完成本机验收。沿用 2.1.0 开发批次，B-02 采购侧提交为 `30774dc`。

## 默认规则

- 公司增加“采购费用计入存货成本”，默认开启；默认分摊方式为金额，可选数量、重量。关闭时，随单费用继续按原规则在第一次收货整笔确认并记采购费用，不追溯已有费用。
- 手工采购费用单用于资本化。关闭开关时不允许新增、提交或过账手工费用单，普通费用继续使用既有费用付款登记；已过账费用仍可查看和冲销。
- 公司未保存业务参数时使用同样的默认值。已按资本化开始确认且仍有余款的订单费用继续原确认路径；关闭开关只把尚未开始确认的费用交给原费用路径，避免中途漏掉余款。
- 费用金额为正，按含税金额及税率拆税。一般纳税人的未税费用进成本，小规模纳税人全额进成本。费用单保存成本含税口径，过账前校验该口径，避免批准后公司身份变化造成结果改变。
- 金额权重采用所选收货尚未退货部分的未税货款，包含有效采购调价；数量采用基本数量，重量采用基本数量乘 SKU 每基本单位重量。权重合计为零时明确要求更换方式或补齐主数据，不均摊掩盖缺失。
- 逐行计算到分，尾差优先计入分摊金额最大的一行，同值按来源编号排序；负尾差和税额分配遵守金额下限及税额不超过含税额的限制，必要时按同样顺序承接。
- 原货款、税额、入库流水和单位成本快照保留。收货详情增加“货款成本、分摊费用、含费用成本”，归集口径同时包括仍在库与已出库的费用。费用不会增加对原商品供应商的退货货款，也不自动退款；全部退货时沿现有零数量残余成本规则处理。

## 随单费用

仅处理采购订单我方承担的费用。开启资本化后，按订单累计收货进度确认费用：用当前批准明细及本次收货后的累计权重计算应确认金额，减此前有效确认额；金额和税额均累计到分，完成收货时补足剩余费用。超收不额外增加订单费用，订单增加数量后累计比例降低时不产生负费用。

本次确认额再分到本次实际收货行。费用随采购订单审批，收货过账时在同一事务自动建立费用归集记录；本次新增数量尚未被其他事务使用，分摊额全部进本次收货仓成本。收货权限与已有流程一致，不要求仓库经办人取得全公司的财务权限。

自动记录只读，不单独重新提交或冲销；通过原收货单整体冲销，反向成本、往来和已确认费用进度在一个事务完成。费用单保留订单费用和收货来源，审批依据可追溯。

订单费用已有归集历史时保留原费用行，即使归集已冲销也不能删除引用。费用不再承担时通过订单变更调整承担方，避免破坏历史来源关系。

保留历史 `recognized_receipt_id`，新增已确认金额与税额。V106 只把历史已确认状态映射到新增进度列，不改变原应付或成本。旧关闭路径和新分批路径产生的往来都支持原采购订单预付款核销及结算汇总。

## 事后采购费用单

- 承运商使用启用的供应商角色；可引用同公司多张已过账收货单的尚未退货行，最多 100 个来源、50 条费用。来源不能有待处理退货或冲销。
- 草稿可改，提交后另一人批准，再在开放期间过账，复用现有工作流、自选复核人、版本及幂等规则。提交、批准和过账均核对来源快照，不能自审。
- 根据每行分摊结果，复用 `ReceiptCostAllocator` 按实际流水重算各仓在库份额；在库费用增加库存成本，已出库和在途部分记成本差异，明细合计等于费用成本。
- 产生承运商应付，按本费用单保存的承运商账期计算到期日；不自动与原商品供应商往来冲抵。费用账期与来源收货的原账期无关。
- 详情、列表、审批列表、财务未清项、报表、冲销和旧幂等响应检查当前权限、部门、来源仓及实际成本归属仓。手工费用成本预览、批准、过账要求完整公司范围及成本权限。
- 过账后仅允许统一冲销。已核销、发票、后续退货及库存使用先处理下游；依赖检查和反向成本写入之间持有库存锁。原收货有有效事后费用时，先冲销费用，才能冲销收货。

## 数据结构（V106）

| 表或字段 | 用途 |
|---|---|
| `company_policy.purchase_fee_cost_enabled/purchase_fee_allocation_method` | 开关与默认方式，旧客户端未传时保留当前值 |
| `purchase_order_fee.recognized_amount/recognized_tax` | 分批确认进度；保留原首次收货关联 |
| `purchase_fee_doc` | 自动或手工来源、承运商、日期、状态、费用及成本合计、账期和归属快照 |
| `purchase_fee_doc_line` | 费用类型、含税额、未税额、税额；自动行关联原订单费用 |
| `purchase_fee_allocation` | 每费用单落到原收货行的合计金额、税额、权重及来源版本 |
| `purchase_fee_cost` | 每分摊行逐仓数量、库存费用、已出库差异及流水水位 |

额外的逐仓成本表避免多仓成本重复计算分摊金额，与 B-02 的来源分摊和逐仓成本分离方式一致。全部关系使用租户、公司复合外键，金额和数量配 CHECK，原迁移文件保持不变。

费用明细保留各行税率与订单费用关系，分摊按费用合计落到来源行；自动随单按订单分别计算后汇入对应来源，不能跨订单分摊。这样结果规模由来源数量与实际仓库决定，避免费用行、收货行和仓库数交叉扩大成本记录。

成本调整新增 `purchase_fee_stock/purchase_fee_issued`，只有前者改变库存成本。自动随单成本来源归原收货，手工费用成本来源归费用单，分别使用明确的来源类型；库存数量、库位、批次和序列号不因此改变。

## 接口与页面

前缀 `/api/v1/purchase-fee-documents`：游标列表、详情、元数据、新建、修改、成本预览和提交、批准、驳回、过账、作废。变更带版本和幂等键，引用来源从授权的已过账收货行中选择。统一冲销增加手工费用单来源。

采购菜单新增费用单，详情继续在右侧打开，关闭保留列表和筛选。表单显示承运商、业务日期、分摊方式、费用明细和原收货来源；预览分列分摊金额、税额、在库成本和已出库差异。收货详情增加费用构成和相关费用记录。公司参数显示开关及默认方式。

## 账务、兼容与验收

自动费用合入原收货的平衡账本和应付，手工费用独立形成账本及承运商应付。借存货或成本差异，借可抵扣进项税，贷应付；大凭证按平衡组拆分。关闭开关时继续原采购费用分录。

扩展采购订单结算、核销、打印、采购报表、应付账龄、来源穿透、库存成本、未清项和关账清单。自动费用不作为独立事实重复汇总；手工费用可单独穿透。成本与总账均排除已出库差异对库存余额的影响。

验收覆盖三种权重、正负尾差、税额上限、两次及多次收货、数量变更、超收、旧已确认费用、开关关闭回归、多供应商和多仓、部分出库后费用、经办复核、幂等与范围、期间关闭、冲销及收货依赖。执行真实总账与八类业务对账、升级演练、前端测试和浏览器验收；第二批最终与 B-04 一起复测总账历史规模。
