设计说明：所有单据列表共用这个模板
  • 对应 pages/SalesListPage.vue、pages/ProcurementListPage.vue、pages/StockOperationPage.vue（列表部分）。各单据只换列，见下一条。
  • 列：发货单换为“发货日期、签收日期、签收状态”；收付款换为“账户、金额、确认状态”；调拨换为“调出仓 → 调入仓”；盘点换为“仓库、快照时间、差异行数”。
  • 状态页签带数量。现有列表只有一个状态下拉框；页签上的数量需要列表接口支持 withTotal，或新增按状态计数的接口。
  • 筛选：现有只有“单号/备注”和“状态”。需要补“客户/供应商、业务日期范围、履约、结算”。后端 SalesOrderController.list 已支持 customerId，还需要增加 dateFrom、dateTo、fulfillmentStatus、settlementStatus。
  • 分页：“共 N 条，第 a—b 条”放在左侧，按钮放在右侧，与面板同样留 16px 内边距（现有页脚紧贴面板边缘）。
  • 筛选条件写入地址栏参数，刷新和从工作台跳转时能还原。
