## 技术选型一览

| 层 | 选型 |
|---|---|
| 后端 | Java 21、Spring Boot 4.1.2、Spring Security + Spring Session（Redis）、JdbcTemplate、Flyway、Spring Modulith；新增 Flowable 8.0.0、Spring WebSocket、Spring Security OAuth2 Client、Spring LDAP、ZXing、OpenSearch Java Client |
| AI 服务 | Spring Boot 4.1.2、Spring AI 2.0.1、Apache Tika、OpenSearch、私有化 bge-m3 / bge-reranker；模型经网关配置 |
| 前端 | Vue 3.5、TypeScript 5.9（strict）、Vite 7、Element Plus 2.11、Pinia 3、vue-router 4、axios、SCSS 设计令牌 + Tailwind；新增 ECharts 6、form-create、bpmn-js、markdown-it + DOMPurify、vue-draggable-plus |
| 移动端 | uni-app（Vue 3 + TypeScript）、wot-design-uni、Pinia |
| 数据 | MySQL 8.0.46（主库 + 只读备库）、Redis、对象存储、OpenSearch |

- 设计变更先改本目录对应文件，再改代码；实施完成后，在文件末尾的修订记录中注明实际与设计的差异。
- 新增业务规则在实施时统一编号写入《业务规则》，本目录中的规则描述以《业务规则》为准。
