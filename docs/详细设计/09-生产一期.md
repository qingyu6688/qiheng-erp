# 09 生产一期：简单装配（2.0.0）

> 对应：《功能扩展方案》第 10 节一期；《企业级演进规划》第 4.3 节。
> 新增包：`mfg`。
> 定位：面向“组装 / 简单加工”型轻制造企业。工艺路线、报工、委外、MES 质检、设备、MRP 不在本版范围（见 2.x 规划）。
> 如果目标客户只做商贸，本模块整体不做。

本机候选实现使用 V92 至 V94。工单下达保留物料和换算快照，生产单据借用现有库存和冲销事务。总账、在制品及库存差异沿用运营账本和原成本调整表。完工估算、逐分分摊和冲回门槛见 [生产业务规则](../业务规则.md#m18-生产库存和月末成本)，接口字段见 [接口设计](../接口设计.md#m18-生产一期接口候选)。

---

## 1. 范围

| 功能 | 说明 |
|---|---|
| 物料清单（BOM） | 多层 BOM、多版本、生效日期、替代料、损耗率 |
| 生产工单 | 计划数量、BOM 版本、领料仓、完工仓、计划日期；工单下达、关闭 |
| 领料 / 退料 | 按工单领料（全部或部分），超领需审批；退料回仓 |
| 完工入库 | 分批完工入库，可超额（按比例上限） |
| 成本归集 | 材料实际成本 + 人工和制造费用分摊；月末计算实际成本并调整产成品成本 |
| 报表 | 工单进度、用料差异（实际 vs 标准）、生产成本明细 |

## 2. 数据模型

### 2.1 BOM

| 表 | 关键字段 |
|---|---|
| `mfg_bom` | `id`、`tenant_id`、`company_id`、`sku_id`（父项）、`version_no`、`base_qty`（如每 1 件 / 每 100 件）、`unit_id`、`valid_from`、`valid_to`、`is_default`、`status`（draft / approved / disabled）、`approver_id`、`version` |
| `mfg_bom_line` | `id`、`bom_id`、`line_no`、`component_sku_id`、`unit_id`、`qty`（相对 `base_qty`）、`scrap_rate`（损耗率 %）、`issue_warehouse_id`（可空 0，用工单默认）、`is_phantom`（虚拟件：展开时穿透）、`remark` |
| `mfg_bom_substitute` | `bom_line_id`、`substitute_sku_id`、`ratio`、`priority` |

规则：

- BOM 审核后不能修改，只能新建版本；同一父项同一时间只能有一个默认版本。
- 保存时检查循环引用（父项出现在自己的下级中），多层展开深度上限 10 层。
- 子件必须是启用的 SKU；子件单位换算使用现有单位换算。

### 2.2 工单

| 表 | 关键字段 |
|---|---|
| `mfg_work_order` | `id`、`tenant_id`、`company_id`、`no`、`sku_id`、`bom_id`、`plan_qty`、`completed_qty`、`issue_warehouse_id`、`receive_warehouse_id`、`plan_start_date`、`plan_finish_date`、`source_type`（manual / sales_order）、`source_id`、`owner_department_id`、`status`（draft / released / in_progress / completed / closed / cancelled）、`over_receive_pct`、`version` |
| `mfg_work_order_material` | `id`、`work_order_id`、`component_sku_id`、`unit_id`、`required_qty`（展开计算并冻结）、`issued_qty`、`returned_qty`、`substitute_of_id` |
| `mfg_issue_doc` / `mfg_issue_line` | 领料 / 退料单：`direction`（issue / return）、`work_order_id`、`warehouse_id`、`status`（draft / pending / approved / posted / reversed）；行：物料、数量、批次、库位、`unit_cost`（过账回填）、`amount` |
| `mfg_receipt_doc` / `mfg_receipt_line` | 完工入库单：`work_order_id`、`warehouse_id`、`qty`、批次、库位、`estimated_unit_cost`、`amount` |
| `mfg_cost_period` | `tenant_id`、`company_id`、`period_id`、`status`（open / calculated / posted） |
| `mfg_cost_item` | `period_id`、`work_order_id`、`material_cost`、`labor_cost`、`overhead_cost`、`wip_begin`、`wip_end`、`finished_cost` |
| `mfg_expense_pool` | `period_id`、`kind`（labor / overhead）、`amount`、`source`（gl / manual）、`allocation_basis`（工时 / 产量 / 材料成本） |

- 工单下达时按 BOM 展开（含损耗）写入 `mfg_work_order_material`，之后 BOM 改版本不影响已下达工单。

## 3. 流程与规则

```text
工单 draft ──下达──► released ──首次领料──► in_progress ──完工数量达到计划──► completed ──关闭──► closed
                                   │                                   │
                       领料、退料、完工入库（各自单据，草稿 → 审核 → 过账）    月末成本计算
```

### 3.1 领料

- 领料单从工单带出待领数量；超过 `required_qty − issued_qty + returned_qty` 时为超领，需要工作流审批（条件变量 `overIssue=true`），没有配置流程时需要第二人审核。
- 过账：按现有出库规则扣减库存，单位成本取移动加权；运营账本：借“在制品 `WIP`”、贷“库存”（新增运营账户码 `WIP`）。
- 批次 / 序列号物料按 06 的规则选择。
- 退料：反向，按原领料成本入库（与现有退货按原成本的思路一致）。

### 3.2 完工入库

- 数量上限：`plan_qty × (1 + over_receive_pct)`。
- 入库成本先按**估算单位成本**入账：估算 = 已领材料成本 ÷ 预计完工数量 + 费用分摊率（上月实际或标准费率）；运营账本：借“库存”、贷“在制品”。
- 产成品进入现有移动加权成本。

### 3.3 月末成本计算

1. 费用池：从总账（1.4.0）取本期“生产成本—直接人工”“制造费用”科目发生额，或手工录入。
2. 分摊：按工单的工时（手工录入）、产量或材料成本比例，把人工和制造费用分到各工单。
3. 在制品：未完工工单按约当产量法或“只留材料成本”法（参数选择）计算期末在制品。
4. 完工实际成本 = 期初在制 + 本期材料 + 本期人工 + 本期制造费用 − 期末在制。
5. 差异 = 实际完工成本 − 已按估算入账的完工成本；用现有 `cost_adjustment` 机制（新增调整类型 `production_variance`）调整产成品库存成本。
   - 产成品仍有库存：差异按现有成本调整规则进入库存成本。
   - 产成品已部分出库：按现有“数量归零尾差”同样的思路，已出库部分的差异计入销售成本（新增运营账户码 `PRODUCTION_VARIANCE`）。
6. 计算结果可以重算，过账后锁定；期间关账前必须完成本期成本计算（加入关账检查项）。

### 3.4 关账检查新增项

- 本期有领料或完工的公司，生产成本已计算并过账。
- 没有已过账但未关联工单的领料单。

## 4. 接口

| 资源 | 路径 | 权限 |
|---|---|---|
| BOM | `/api/v1/mfg/boms`、`/{id}/{submit\|approve\|disable}`、`/{id}/explode?qty=` | `mfg_bom:*` |
| 工单 | `/api/v1/mfg/work-orders`、`/{id}/{release\|close\|cancel}`、`/from-sales-order` | `mfg_work_order:*` |
| 领退料 | `/api/v1/mfg/issues`、`/{id}/{submit\|approve\|post}` | `mfg_issue:*` |
| 完工 | `/api/v1/mfg/receipts`、`/{id}/{submit\|approve\|post}` | `mfg_receipt:*` |
| 成本 | `/api/v1/mfg/cost-periods/{periodId}/{collect\|allocate\|calculate\|post\|recalculate}` | `mfg_cost:*` |
| 报表 | `/api/v1/mfg/reports/{progress\|material-variance\|cost-detail}` | `mfg_report:view` |

冲销：领料单、完工入库单加入现有冲销框架；已参与成本计算并过账的期间内单据，冲销需要先重开期间。

## 6. 迁移规划

1. `mfg_bom`、`mfg_bom_line`、`mfg_bom_substitute`
2. `mfg_work_order`、`mfg_work_order_material`
3. `mfg_issue_*`、`mfg_receipt_*`；冲销来源类型扩展
4. `mfg_cost_period`、`mfg_cost_item`、`mfg_expense_pool`；`cost_adjustment.adjust_type` 增加 `production_variance`
5. 运营账户码 `WIP`、`PRODUCTION_VARIANCE` 及总账默认映射（生产成本、主营业务成本）
6. 关账检查项、权限码

## 7. 测试要点

1. BOM 循环引用被拒绝；虚拟件展开穿透；损耗率计算正确（向上取整规则写入《业务规则》）。
2. 超领需要审批；退料按原成本入库。
3. 完工超过上限被拒绝。
4. 成本计算：样例（两层 BOM、两张工单、一张未完工）逐分核对；差异调整后，产成品库存成本 + 已售成本差异 = 实际完工成本。
5. 在制品对账：`WIP` 运营账户余额 = 各未完工工单的期末在制成本合计。
6. 冲销领料后，工单已领数量和在制品同步恢复。

## 8. 验收

两层 BOM（成品 ← 半成品 ← 原材料，含一个替代料）：半成品工单领料、完工 → 成品工单领料（含半成品）、分两批完工 → 月末归集人工和制造费用、计算成本 → 差异调整 → 关账；成品单位成本与手工计算结果一致，总账生产成本科目期末余额等于在制品。
