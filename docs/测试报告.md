## 0.2.0 验收记录

环境继续使用 Windows 11、JDK 21.0.3、MySQL 8.0.46、项目独立 Redis 及 Node.js 24.9.0。

M2 的回归覆盖组织、权限及基础资料。数据库测试使用独立的 `erp_test`，常规用例事务回滚；并发取号用例只清理自己创建的租户数据。浏览器测试使用每轮创建的随机测试企业与临时口令。

| 范围 | 检查内容 |
|---|---|
| 组织权限 | 公司和参数审计、角色授予范围、跨租户查询、管理员交接保护、重置密码后旧会话失效、手机号省略 |
| 商品 | 分类循环、SKU归属、单位条码、单据引用后的换算保护、停用资料、新建与重试 |
| 字段权限 | 联系方式省略、完整银行账号脱敏、采购价读写权限、幂等缓存及审计中的敏感数据处理 |
| 资金与期间 | 创建账户时同事务建立零余额，编辑保留隐藏账号，逐月开启会计期间 |
| 单号 | 多公司与类型并发取号、业务回滚保留断号、号段耗尽、16字符公司编码生成33字符单号并实际落库 |
| 审计 | 可见范围内分页，两页无重复，隐藏其他公司和租户记录 |
| 浏览器 | 仓库原流程，以及单位、分类、商品、SKU条码、往来客户、角色、用户范围、结算账户、期间、重置密码后改密 |

后端 `mvn verify` 已通过 91 项测试（8 项单元/模块测试与 83 项集成测试），全部无失败、无跳过。前端 ESLint、TypeScript、生产构建和 25 项 Vitest 已通过。浏览器端到端测试 2 项全部通过，覆盖新资料与授权改密流程、原仓库流程，运行期间 `pageerror` 为零。启动方式见[部署说明](部署说明.md)。
