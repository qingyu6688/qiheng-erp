# 柒衡 ERP 2.0 不兼容变更预告

计划在 2.0 上线时调整三项现有行为。请在 1.x 后续版本的试运行中检查当前企业配置。

| 调整 | 升级前检查 |
| --- | --- |
| 移除业务单据的单级审批回退 | 为仍使用单级审批的单据配置并发布审批模型，绑定到实际公司。验证提交、人工复核、驳回和撤回。按旧规则启动的在途单据应先完成或撤销。 |
| 统一部门数据范围 | 为角色明确设定公司范围、仓库授权和部门规则，使用普通角色检查列表、详情、导出、打印和历史任务。确认只有被授权的公共资料能跨部门读取。 |
| 总账科目映射必填 | 在每个已启用账套中补齐业务事件和辅助维度的科目映射。以购销、资金和成本样例验证凭证平衡以及财务与运营账本的对账。 |

具体生效版本、迁移脚本、停机窗口与回滚步骤由 2.0 发布说明确认。M14 候选可用来准备流程和权限配置。
