# 更新日志

按日期倒序记录文档和工程的版本变化。规则变更写明受影响的规则编号。

## 2026-11-15

### 0.4.0 · 销售闭环

- 接入销售订单的草稿、提交库存提示、审批预留、撤回驳回、撤销审批、关闭剩余、取消、变更与重新预留。实时库存展示待审核需求，商品、单位与税额保存计算快照。
- 接入发货提交占用、作废、过账出库、客户签收、拒收退回与运输损失、自提即签收和超期提醒。应收按签收累计确认，运费首次签收确认，预收自动核销。
- 接入收款登记确认、未清项手工核销与撤销、按原发货退货、信用额与原收款双重额度退款、审核分离与手工登记退款。退货沿用原成本和税额快照。
- 接入开票登记和作废，只更新开票关联及 `invoiced_amount` 元数据；原应收、税额、未清项和账本保持来源业务金额。
- 对齐 B06 验收措辞与接口 6.2：客户端计算字段仍由服务端忽略并重算，验证保存值不会被篡改；R3-12 金额勾稽和计算规则不变。
- 增加 V15、V16、V18、V19 增量迁移及销售操作权限，命令沿用 MySQL 幂等、版本与数据范围校验。前端新增销售列表、详情、录入、签收、库存及核销工作台，变更审批与命令超时可查询原键结果。
- 新增 SO-3、SO-4、45.83/5.27 退货退款、20 轮审批并发、历史快照、权限和开票测试；本地销售浏览器夹具只在测试 classpath 使用当前期间。后端199项、前端40项、浏览器3项全部通过，构建与lint通过，样例8类对账零差异，记录见《测试报告》。

### 0.3.0 · 正确性底座

- 本机开发登录页预填企业和管理员，默认密码通过根目录私有配置注入。已同步本机开发账号，生产构建清空默认值。
- 新增价格引擎、库存及预留、移动加权成本、订单行占用、未清项核销、退款额度、过账、期间共享锁和账本投影。
- 新增 Outbox 租约、有限重试、死信与重放、Inbox 去重和到期预留任务。通用命令规范化JSON摘要并兼容旧摘要，仓库命令复用同一实现。
- 新增8类对账及异步API，执行时复核发起人范围。V9—V14补齐权限、价格快照、调拨累计成本、对账精度及投影协调。
- 后端152项、前端26项及2项浏览器回归通过，构建和lint通过。库存与核销并发各20轮，Redis不可达、任务中断、乱序投影和金额落库均已覆盖。本机真实异步对账完成且差异为零。
