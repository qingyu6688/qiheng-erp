登录

连续输错 5 次密码，账号会锁定 15 分钟。忘记密码请联系系统管理员重置。

用户名或密码错误
未知用户和密码错误用同一句提示，提示条放在“登录”标题下方。
登录失败次数过多
请 15 分钟后再试。锁定期间“登录”按钮可点，但直接显示这条提示。
正在登录…
按钮显示加载状态并禁用，防止重复提交。
设计说明
  • 对应 pages/LoginPage.vue，现有页面结构基本一致，本稿只补充三种状态的样式和位置。
  • 企业编码记住上次输入，存在 localStorage，读写都要包在 try/catch 里；用户名和密码不保存。
  • 开发环境的预填账号只在 npm run dev 时注入（现有 vite.config.ts 已如此），生产构建为空。
