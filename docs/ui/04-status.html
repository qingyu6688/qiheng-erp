状态页（401 / 403 / 404 / 503）
401

登录已过期

为了账户安全，超过 30 分钟未操作或登录超过 12 小时需要重新登录。未保存的内容不会保留。

重新登录
403

没有访问权限

你的角色没有“销售订单 · 查看”权限，或当前公司不在你的数据范围内。如需开通，请联系系统管理员。

回到工作台
404

页面或单据不存在

单据可能已被删除，或不属于当前公司。可以切换公司后再试。

回到工作台
503

服务暂时不可用

无法连接到服务器。已提交的单据不会丢失，请稍后刷新页面。

设计说明
  • 对应 pages/StatusPage.vue。现有页面已有四种状态，本稿统一文案：每页都说明原因和下一步可以做什么。
  • 403 页面在知道缺少哪个权限时显示权限名称（路由 meta.permission），不知道时只显示通用说明。
  • 状态页不显示左侧菜单，避免在无权限时出现可点但进不去的入口。
