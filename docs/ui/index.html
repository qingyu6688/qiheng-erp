后台页面设计稿

配合《UI 设计规范》和《优化文档》第 4、5 节使用。每个页面底部的“设计说明”写明对应的 Vue 文件、依赖的接口和需要改动的地方。

本目录是静态 HTML，直接双击打开即可；也可以在 docs/ui 目录执行 python -m http.server 8765 后访问 http://127.0.0.1:8765/。公共样式在 assets/erp-ui.css，左侧导航和顶栏由 assets/shell.js 生成，导航分组即 O-12 建议的新结构。
