# 第三方依赖说明

本项目代码继续采用 AGPL-3.0-only。第三方组件适用各自许可证，打包时保留原组件提供的版权、许可和 NOTICE。文档维护人使用 `maorongkang@gmail.com`。

| 组件 | 版本及用途 | 许可来源 |
| --- | --- | --- |
| Spring Boot WebSocket starter / Spring WebSocket | 版本由现有Spring Boot4.1.2依赖管理决定，用于服务端实时摘要推送，未升级主框架。 | [Spring Framework源码许可](https://github.com/spring-projects/spring-framework/blob/main/LICENSE.txt)，发行依赖中的META-INF许可随JAR保留。 |
| jsoup | 1.24.1，用于公告HTML白名单清洗。 | [jsoup官方许可](https://jsoup.org/license)，jsoup嵌套JAR中保留META-INF/jsoup/LICENSE。 |

行政区划属于公开数据来源说明，版本、来源页面及校验值见[区划数据来源](区划数据来源.md)。未使用备用第三方区划包，不将其作为本项目数据来源。

依赖通过Maven管理，交付的Spring Boot JAR保留对应嵌套依赖，不移除其中的许可与版权声明。前端沿用已有Vue、Element Plus等依赖及其许可，未替换项目主许可证。

原始许可及NOTICE的副本见[第三方依赖许可](第三方依赖许可.md)。

## M11 工作流引擎

使用 `org.flowable:flowable-spring:8.0.0` 内嵌 BPMN 引擎，许可为 Apache-2.0，原文见[第三方依赖许可](第三方依赖许可.md#flowable-800-引擎声明)。不引入 Flowable REST、IDM、事件注册服务、外部设计器或新的前端依赖。引擎与业务共用 JDK21、Spring Boot BOM 管理的 Spring/Jackson 版本及同一事务管理器；API 不开放原始流程 XML、脚本和任意 Bean。V44 保留原版 MySQL DDL 及来源摘要，运行时关闭自动 DDL。

## M13 内部 AI 助手

`erp-ai` 使用 Spring AI 2.0.1 的 `ChatModel` 接口和 Apache Tika 3.3.3 的文档解析组件，均采用 Apache-2.0，嵌套依赖保留发行 JAR 的许可和 NOTICE。可选搜索容器使用 OpenSearch 3.9.0，许可和通知随镜像提供。前端使用 markdown-it 15.0.3 渲染 Markdown，以及 DOMPurify 3.4.18 清洗生成的 HTML。markdown-it 采用 MIT，DOMPurify 可按 Apache-2.0 使用，许可声明见[第三方依赖许可](第三方依赖许可.md#m13-前端-markdown-渲染)。

## M14 平台二期

OIDC 验签使用 Spring Security JOSE，版本由 Spring Boot 依赖管理提供，保持 Apache-2.0 许可。前端工作流使用 bpmn-js 和 FormCreate，MFA 使用 qrcode。需要保留 BPMN 画布上的 bpmn.io 标识，使用页面随前端发布的许可声明。[前端依赖许可](../erp-web/public/第三方许可.md)

## M14 供应链一期

`com.google.zxing:core:3.5.4` 用于库位标签 Code 128 编码，采用 Apache-2.0。发布的 Spring Boot JAR 保留嵌套依赖携带的版权和许可证文件。渲染 PNG 使用 JDK `java.desktop`，部署使用带该模块的 JDK 21 运行时。 [ZXing 源码许可](https://github.com/zxing/zxing/blob/zxing-3.5.4/LICENSE)

## M16 门户对账 PDF

`org.apache.pdfbox:pdfbox:3.0.8` 用于生成门户对账 PDF，同时带入 `fontbox` 和 `pdfbox-io` 3.0.8。三项依赖采用 Apache-2.0，嵌套 JAR 保留各自的 `META-INF/LICENSE` 和 `META-INF/NOTICE`。中文字体由部署环境提供并按字体本身的许可使用。 [Apache PDFBox 项目许可](https://pdfbox.apache.org/)
