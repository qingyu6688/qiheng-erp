# 文档目录

文档按用途分到六个子目录，根目录保留文档索引、《更新日志》和公开部署资料检查说明。新增文档时放进对应目录，并在这里补一行。

| 目录 | 放什么 | 先看 |
|---|---|---|
| [产品](产品/) | 面向使用者的总说明：操作手册、业务规则、第三方依赖 | [用户使用手册](产品/用户使用手册.md)、[业务规则](产品/业务规则.md) |
| [使用说明](使用说明/) | 按模块拆开的使用与验收说明（M11—M15）、登录和数电发票配置 | [人工智能使用与验收](使用说明/M13人工智能使用与验收.md)、[开放平台接入手册](使用说明/M14开放平台接入手册.md) |
| [设计](设计/) | 数据库、接口、UI 规范和各模块的实施设计；`详细设计/` 是 1.1 → 2.0 的分册 | [数据库设计](设计/数据库设计.md)、[接口设计](设计/接口设计.md)、[详细设计](设计/详细设计/README.md) |
| [运维](运维/) | 部署、日常运维、升级和上线检查 | [部署说明](运维/部署说明.md)、[运维手册](运维/运维手册.md)、[1.x 升级到 2.0 指南](运维/1.x升级到2.0指南.md) |
| [测试](测试/) | 测试报告、容量测试和造数脚本说明；`验收记录/` 是各里程碑的本机验收和演练报告 | [测试报告](测试/测试报告.md)、[容量测试报告](测试/容量测试报告.md) |
| [规划](规划/) | 开发计划、待办优化、企业级差距与路线图、项目总结 | [企业级演进规划](规划/企业级演进规划.md)、[优化文档](规划/优化文档.md) |

## 按角色找

- **使用系统**：[用户使用手册](产品/用户使用手册.md) → 对应模块的[使用说明](使用说明/)。
- **部署和运维**：[部署说明](运维/部署说明.md) → [运维手册](运维/运维手册.md) → [上线准备清单](运维/上线准备清单.md)；从 1.x 升级先读[不兼容变更预告](运维/2.0不兼容变更预告.md)。
- **二次开发和接口对接**：[业务规则](产品/业务规则.md) → [数据库设计](设计/数据库设计.md) → [接口设计](设计/接口设计.md) → [开放平台接入手册](使用说明/M14开放平台接入手册.md)。
- **了解进度和后续计划**：[更新日志](更新日志.md)、[开发计划](规划/开发计划.md)、[企业级演进规划](规划/企业级演进规划.md)。

## 约定

- 文档之间用相对路径链接；移动文件时用 `git mv`，并同步改链接。
- `产品/业务规则.md`、`产品/用户使用手册.md`、`运维/运维手册.md` 会作为 AI 知识库的种子文档打进 `erp-ai`（见 `erp-ai/pom.xml`），改名或移动时要同步修改。
- 发布包附带的文档清单在 `scripts/package-release.ps1` 的 `$documents` 中维护。
- 服务器地址、账号等私有部署资料不放进本目录的公开文件。
