## 0.7.0 新增环境约定

本轮继续使用下表已记录的本机版本，未升级 JDK 或 MySQL，也未引入 Python 业务依赖。后端新增 S3 兼容客户端用于可配置对象仓；开发、测试及本机 E2E 在未配置 S3 时使用运行用户目录下 `.erp/private-objects`，通过 `erp.storage.local-root` 可改为专用私有目录。普通生产配置必须完整提供 `STORAGE_ENDPOINT/STORAGE_BUCKET/STORAGE_ACCESS_KEY/STORAGE_SECRET_KEY`，不允许静默使用本机目录。文件凭据只存在 `.env` 或服务器环境配置中。

API 和 Worker 需要访问同一数据库、Redis 与对象仓；`ERP_WORKER_ENABLED=false` 只关闭当前实例的后台执行，须保留另一个开启 Worker 的实例。上传单文件 20MB，multipart 总请求上限至少 21MB。前后端开发端口 8080/5173、浏览器验收端口 18080/15173 均沿用现有约定。测试仍使用隔离 `erp_test` 库和随机测试企业。

升级时新增 Flyway V28—V31。M7 后端 362 项、前端 101 项及浏览器 9 条流程通过，构建和检查结果已在《测试报告》登记；本节的工具版本为既有实测记录，不将未执行的外部 S3、生产部署或恢复演练记为已验证。

V31 记录导入基础设施故障的尝试次数及下次执行时间，最多自动执行 3 次、退避 2 和 4 秒；原操作人可在依赖恢复后幂等继续未处理行。该功能不增加新服务或端口，仍依赖现有 MySQL、私有文件仓与开启的 Worker。

## 环境变量约定

仓库提供不含真实凭据的 `.env.example`，实际 `.env` 加入 `.gitignore`。至少说明下列变量：

| 变量 | 含义 |
|---|---|
| APP_ENV | 开发、测试或生产环境 |
| SERVER_PORT | 后端服务端口 |
| DB_HOST / DB_PORT / DB_NAME | 数据库地址、端口和库名 |
| DB_USER / DB_PASSWORD | 最小权限数据库账号及密码 |
| REDIS_HOST / REDIS_PORT / REDIS_PASSWORD | Redis 连接配置 |
| STORAGE_ENDPOINT / STORAGE_BUCKET | 附件对象存储地址和存储桶 |
| STORAGE_ACCESS_KEY / STORAGE_SECRET_KEY | 对象存储凭据 |
| SESSION_SECRET | 如认证方案需要，用于会话签名或加密 |
| OTEL_EXPORTER_OTLP_ENDPOINT | 如启用链路追踪，指定数据接收地址 |

租户、公司、用户和数据权限从经过认证的服务端上下文取得，不能通过环境变量或前端传参冒充。
