## 环境变量约定

仓库提供不含真实凭据的 `.env.example`，实际 `.env` 加入 `.gitignore`。至少说明下列变量：

| 变量 | 含义 |
|---|---|
| APP_ENV | 开发、测试或生产环境 |
| SERVER_PORT | 后端服务端口 |
| DB_HOST / DB_PORT / DB_NAME | 数据库地址、端口和库名 |
| DB_USER / DB_PASSWORD | 最小权限数据库账号及密码 |
| REDIS_HOST / REDIS_PORT / REDIS_PASSWORD | Redis 连接配置 |
| STORAGE_ENDPOINT / STORAGE_BUCKET | 附件对象存储地址和存储桶 |
| STORAGE_ACCESS_KEY / STORAGE_SECRET_KEY | 对象存储凭据 |
| SESSION_SECRET | 如认证方案需要，用于会话签名或加密 |
| OTEL_EXPORTER_OTLP_ENDPOINT | 如启用链路追踪，指定数据接收地址 |

租户、公司、用户和数据权限从经过认证的服务端上下文取得，不能通过环境变量或前端传参冒充。
