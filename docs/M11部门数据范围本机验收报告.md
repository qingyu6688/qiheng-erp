## 1. 交付内容

角色按公司设置全部、本部门、本部门及下级、仅本人和自定义五种范围，复用角色权限设置面板；未配置角色默认全部。多个启用角色取并集，再与原企业、公司、仓库及操作权限取交集。公司独立版本、CSRF、幂等和审计保持完整，前端处理未保存、切公司迟到响应、未知结果原键重试及版本冲突。

V37为17类业务头增加归属部门、归属人与两类索引，历史按创建人当前公司主部门回填，无法归属保持0；冲销继承原单归属。新建归属由服务端冻结，人员调动和部门移动不回写历史。受限用户无有效主部门或主部门不在可写范围时建单422。

列表、计数、来源候选、详情、写命令、旧幂等结果、工作台、报表、打印及附件统一校验。授权从主库读取，单次请求复用，下一请求立即反映撤权；对象读取结束后再次复检。导出保存初始边界，执行与即时授权取交集，生成和下载检查范围；导入逐行授权并保留发起边界。工作台金额缓存键包含部门条件摘要。

本部门取当前公司全部启用任职部门，主部门只用于新单。部门树、用户任职维护要求当前公司全部部门范围；企业级角色、权限、公司范围、状态及口令管理要求操作者在所授权公司均拥有全部部门范围，防止间接扩大自身可见范围。最后全范围有效角色管理员不能被移除。

## 2. 权限验证

| 场景 | 结果 |
| --- | --- |
| 四种受限模式、未配置角色及多角色并集 | 按规则合并，部门范围不能授予公司、仓库或操作权限 |
| 同公司另一部门单据、另一公司或企业引用 | 详情、写命令、打印和附件拒绝，404不暴露对象存在性 |
| 17类业务头详情 | 有权时可读，空自定义范围逐类404 |
| 同一会话收紧角色范围 | 下一请求的列表、total、详情和旧命令结果立即受限 |
| 部门移动及任职变化 | 后代范围下一请求更新，历史owner字段保持不变 |
| 未归属历史 | 仅全部范围可见，不能通过仅本人模式绕过 |
| 跨公司配置及版本 | 甲、乙公司配置和版本独立，跨公司部门、跨企业角色404 |
| 管理员间接提权与锁死 | 受限账号分配全部角色、改本人任职、移动部门均403；限制或撤销最后全范围管理员422并回滚 |
| 报表及缓存 | 事实在聚合前过滤；非空样例在受限范围下不泄漏，金额缓存按组织条件隔离 |
| 冲销 | 继承原单归属，保留反向事实；不可见下游仍阻止冲销，但不返回其标识与单号 |
| 附件慢读取期间撤权 | 下载返回404，响应不包含文件字节 |
| 导出授权扩大及撤销 | Worker保持初始部门边界，收窄后拒绝历史文件下载，恢复后可下载未过期结果 |
| 导入断点后扩大授权、改变主部门 | 新主部门不在初始范围时不产生越界草稿，保留已提交行及错误结果 |

库存当前余额、预留、冻结和可用量继续表示授权仓库的共享实物快照。待审需求、未签收统计和可追溯收发事实按部门过滤；范围内收发事实不能用于声称全仓余额一致。报表显示口径说明，受限用户不返回资金账户全公司余额。全公司关账、对账、运维和公司整单审计要求全部部门范围。
