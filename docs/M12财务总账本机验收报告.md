## 已定位并修正的问题

1. MySQL unsigned编号返回BigInteger，坏账来源校验不能用equals(Long)，改用数值比较并验证核销链路。
2. 旧业务无启用账套时，新增总账对账项不应要求财务权限；调整后继续保留原八类对账行为，有账套及显式财务任务仍强制权限。
3. 通用幂等结果入口补齐财务/应收命令白名单并重查当前权限，修正催收实际命令名。
4. 辅助和模板编号按字符串序列化，避免浏览器精度损失；切公司丢弃迟到响应。
5. 同辅助税金子科目先净额，跨客户不抵销；年初数与年中现金流累计明确区分。
6. 财务页面补齐按需日期、页签、提示、空状态、步骤条及加载指令，真实浏览器覆盖制单到下载，修正实际XLSX的下载名称。
7. 控制器只接收请求；同步编排与往来资料查询移至服务层。同步命令使用READ_COMMITTED，逐条独立事务完成后读取最新剩余数量。
8. 账套启用先锁期间再锁账套，避免与旧业务关账并发交错；配置及已用凭证字保持历史规则。
