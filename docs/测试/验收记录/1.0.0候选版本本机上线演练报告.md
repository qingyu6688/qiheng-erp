# 1.0.0-rc.1 本机上线演练报告

演练日期为 2026-11-15，时间按北京时间记录。使用 Windows、JDK 21.0.3、原有 MySQL 8.0.46、Redis 和模拟业务数据。后台和浏览器均从候选 ZIP 解包启动。

API 和 Worker 使用同一演练库和本机私有文件对象仓，各自使用独立节点号。本机采用支持文件对象仓的应用配置，显式启用 HTTPS 会话 Cookie 和转发头，并关闭 OpenAPI 和演示账号初始化。Redis 使用本轮专用会话命名空间。真实渠道凭据、正式对象仓和生产证书在目标环境验收中配置。

## 功能模块验收

| 模块 | 结果 |
| --- | --- |
| 安装与身份 | 空库迁至 Flyway V33。包内初始化工具生成一个企业、公司和管理员，重复执行被拦截。首次登录须修改密码。已授权管理员可保存登录方式设置，复核员访问返回 403 |
| 数据库分权 | 运行、迁移、备份账号分离并要求 TLS。运行账号能追加业务事实，DDL、改审计、改删凭证和改权限目录均被拒绝。迁移账号通过 DDL 探测，备份账号写入被拒绝 |
| 期初及导入 | 库存 CSV 两行，一行成功、一行失败。错误清单保留原列和原因，重传复用原任务。异人审核后过账，库存 20 件、成本 240.00 元。资金期初 1000.00 元、应收 50.00 元、应付 35.00 元 |
| 采购和销售 | 采购收货 10 件，付款 175.00 元并核销采购及期初应付。销售 3 件，签收后确认应收，收款 110.00 元并核销销售及期初应收。最终在库 27 件、成本 342.00 元、资金 935.00 元，应收应付未清项均为零 |
| 库存、财务与后台任务 | 异人审核库存调整并冲销。停 Worker 后实际关账并补投影两笔凭证，再重开期间。Worker 重启后待处理与失败事件均为零，八类对账差异均为零 |
| 报表、附件和审计 | 库存 CSV 导出下载须取得票据。私有附件下载与上传内容摘要一致，匿名访问被拒绝。销售打印数据可读取，登录设置变更审计返回带时区的时间 |
| HTTPS 管理端 | 从解包静态资源校验工作台、期初导入、报表导出、库存汇总、销售订单和登录设置，页面错误为零。导入任务 `2026-11-15T15:21:45.467Z` 显示为 `11-15 23:21` |

源码回归通过 44 项后端单元测试、366 项后端集成测试、156 项前端测试和 11 条 Chrome 端到端用例，ESLint、JAR 和前端生产构建通过。

## 停写、备份和恢复

API 与 Worker 停机后，分别取得开账前和试运行后的独立数据库及对象仓备份，记录 binlog 水位及文件摘要。两个备份恢复到不同的隔离库。

| 恢复点 | 结果 |
| --- | --- |
| 开账前 | 1 个企业、1 条引导审计，库存调整、财务期初、购销订单和凭证均为零 |
| 试运行后 | 源库和恢复库均为 2 张库存调整、3 张财务期初、1 张采购订单、1 张销售订单、11 张凭证及 69 条审计记录 |
| 恢复核验 | 3 个私有对象逐项核对摘要一致。直接运行解包内的恢复核验脚本，1 家公司、11 张凭证重复执行八类对账，差异均为零 |
| 旧数据升级 | 将 0.8.1 演练的 V31 期末快照恢复至独立库，使用候选 JAR 经 V32、V33 升级。单据、凭证、库存数量和成本与迁移前一致，既有系统管理员具备新权限，恢复后八类对账差异均为零 |

原始日志、命令结果和恢复清单位于忽略目录 `.local/pilot-m9-20261115231829-ee41a8`。源码回归日志位于 `.local/m9-release`。
