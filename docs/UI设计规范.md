# ERP 管理端 UI 设计规范

- 规范版本：2.0.0（大厂中后台风格）。
- 编写日期：2026-11-17，Asia/Shanghai。
- 适用范围：柒衡 ERP 管理端（`erp-web`）、客户门户、移动端（`erp-mobile`）。
- 设计稿：`docs/ui/v2/`（入口 `docs/ui/v2/index.html`）。1.0 版设计稿 `docs/ui/` 已在 0.8.0 实现，保留作历史参考；新页面和改版以 v2 为准。
- 依据：全局规范第 14 节，《接口设计》第 2.5、2.9、2.12 节，《业务规则》第 11 节，《详细设计》00 第 3 节。
- 文档维护：maorongkang@gmail.com。

## 1. 设计方向

### 1.1 定位

对齐国内大厂中后台的通用做法（Ant Design 5、Arco Design、TDesign 的共同规范），**继续使用 Element Plus**，通过设计令牌、全局尺寸和少量通用组件统一风格，不更换组件库，不改变任何接口和业务行为。

### 1.2 原则

1. **高密度、可扫读。** 用户整天录单、对账。默认控件 32px、表格行 40px，1440×900 屏幕一屏至少显示 12 行明细；用对齐、留白和字重区分层级，不靠大卡片、大字号、渐变和装饰图。
2. **一种页面一个模板。** 列表、编辑、详情、审批、主从资料、工作台各有固定骨架（第 5 节），新页面先套模板再填内容。
3. **操作位置固定。** 页面主操作在页头右侧；编辑页的保存、提交固定在底部操作栏；行操作固定在表格最右列；批量操作出现在表格上方。
4. **颜色只表达状态和主操作。** 其余一律中性灰；同一区域主按钮只有一个。
5. **服务端说了算。** 金额、合计、可用量都由接口返回，页面只显示；按钮按接口返回的 `allowedActions` 显示。
6. **每种状态都要设计。** 空数据、加载中、失败、结果确认中、数据被他人修改，都有对应样式。
7. **信息不重复。** 页面名只在页头出现一次；顶栏不放面包屑和页面名。
8. **可访问。** 所有文字（含按钮文字、占位符、表头）与背景对比度不低于 4.5:1；状态标签始终带文字；图标按钮有 `aria-label`；所有功能可用键盘完成。

## 3. 设计令牌

页面样式只引用 `--erp-*` 或 `--el-*` 变量，不出现裸色值。完整定义见 `docs/ui/v2/assets/v2.css` 顶部 `:root`。

### 3.1 品牌色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--erp-primary-1` | `#E8F3FF` | 选中行、选中菜单背景、信息标签底 |
| `--erp-primary-2` | `#BEDAFF` | 标签边框、焦点外圈 |
| `--erp-primary-5` | `#4080FF` | 悬停 |
| `--erp-primary-6` | `#165DFF` | **主色**：主按钮（白字对比度 5.2:1）、链接、选中、焦点 |
| `--erp-primary-7` | `#0E42D2` | 按下；浅底上的主色文字 |

### 3.2 功能色

| 语义 | 鲜艳色（图标、徽标、图表、边框） | 浅底（标签背景） | 文字色（白底 ≥ 4.5:1，Element Plus 基色） |
|---|---|---|---|
| 成功 | `#00B42A` | `#E8FFEA` | `#0B7A26`（5.4:1） |
| 警告 | `#FF7D00` | `#FFF7E8` | `#B24A00`（5.3:1） |
| 危险 | `#F53F3F` | `#FFECE8` | `#CB2634`（5.4:1） |
| 信息 / 进行中 | `#165DFF` | `#E8F3FF` | `#0E42D2` |
| 中性 | `#86909C` | `#F2F3F5` | `#4E5969` |

鲜艳色做文字时对比度只有约 2.6—3.7:1，**不能用作文字和按钮文字**；所有文字、描边按钮、链接、消息正文使用“文字色”列。

### 3.3 中性色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--erp-text-1` | `#1D2129` | 标题、正文、表格内容 |
| `--erp-text-2` | `#4E5969` | 次要正文、表单标签 |
| `--erp-text-3` | `#6B7380` | 辅助说明、表头、占位符（4.7:1） |
| `--erp-text-4` | `#86909C` | 禁用文字、图标（禁用态不要求对比度） |
| `--erp-border-1` | `#E5E6EB` | 卡片边框、分隔线 |
| `--erp-border-2` | `#C9CDD4` | 输入框边框（与白底约 1.6:1，低于 WCAG 非文本 3:1；输入框必须同时有可见标签，聚焦时用主色描边，对比度 5.2:1） |
| `--erp-divider` | `#F2F3F5` | 表格行分隔线 |
| `--erp-fill-1` | `#F7F8FA` | 表头、悬停行、只读输入 |
| `--erp-fill-2` | `#F2F3F5` | 页面背景、中性标签底 |
| `--erp-bg` | `#FFFFFF` | 卡片、弹窗、下拉 |

### 3.4 文字

字体：`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif`；数字开启 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 指标 | 28 / 36 | 600 | 工作台、驾驶舱主数字 |
| 页面标题 | 20 / 28 | 600 | 页头标题（每页一个） |
| 区块标题 | 16 / 24 | 600 | 卡片标题、抽屉标题 |
| 正文 | 14 / 22 | 400 | 默认 |
| 强调 | 14 / 22 | 500 | 表头、合计、表单分组名 |
| 辅助 | 12 / 20 | 400 | 说明、时间、徽标、表格次行 |

### 3.5 间距、圆角、阴影

- 间距以 4px 为基数：`4 / 8 / 12 / 16 / 20 / 24 / 32`。卡片内边距 16px（页头 20px）；卡片之间 16px；表单项横向、纵向 16px。
- 圆角：标签 2px；按钮、输入框、下拉 4px；卡片 6px；弹窗、抽屉 8px。
- 阴影（卡片默认只有边框）：

| 层级 | 值 | 用途 |
|---|---|---|
| 1 | `0 1px 2px rgba(29,33,41,.06)` | 底部操作栏、吸顶表头 |
| 2 | `0 4px 10px rgba(29,33,41,.10)` | 下拉、气泡 |
| 3 | `0 8px 24px rgba(29,33,41,.12)` | 弹窗、抽屉、全局搜索 |

### 3.6 尺寸与密度

| 元素 | 紧凑 | **默认** | 宽松 |
|---|---|---|---|
| 按钮、输入框、下拉 | 24px | **32px** | 36px |
| 表格表头、行 | 32px | **40px** | 48px |
| 可编辑明细表行 | — | **36px** | — |
| 菜单项 | — | **36px** | — |
| 页签栏 | — | **36px** | — |
| 顶栏 | — | **56px** | — |

用户可在表格工具栏切换密度，设置按用户保存在 `localStorage`（读写包 `try/catch`，失败按默认密度）。

### 3.7 动效与层级

- 时长：悬停、展开 150ms；抽屉、弹窗 200ms；缓动 `cubic-bezier(.34,.69,.1,1)`；尊重 `prefers-reduced-motion`。
- 层级：吸顶表头 10、底部操作栏 20、顶栏 100，其余沿用 Element Plus 递增的弹层层级。

## 4. 布局与导航

### 4.1 外壳

```text
┌──────┬────────────────────────────────────────────────────────────────────┐
│ 模块栏│ 顶栏 56px：收起 · 全局搜索(Ctrl+K)            公司 ▾  通知  帮助  用户 ▾ │
│ 64px ├───────────┬────────────────────────────────────────────────────────┤
│ 图标 │ 菜单栏      │ 页签栏 36px：工作台 · 销售订单 × · SO-…-0123 ×            │
│ +文字│ 208px      ├────────────────────────────────────────────────────────┤
│      │ 当前模块的  │ 内容区（背景 --erp-fill-2，内边距 16px）                   │
│      │ 二级菜单    │   页头 → 查询卡 → 表格卡 …                                 │
└──────┴───────────┴────────────────────────────────────────────────────────┘
```

- 模块栏、菜单栏、顶栏、页签栏固定，只有内容区滚动。
- 菜单栏可收起（按钮或快捷键 `[`），收起后鼠标悬停模块图标弹出二级菜单。
- 屏宽 < 1200px 时菜单栏默认收起；< 768px 时两栏合并为抽屉。

### 4.2 模块划分

| 模块 | 二级菜单 |
|---|---|
| 工作台 | 工作台、经营驾驶舱 |
| 销售 | 销售订单、发货与签收、销售退货、价格表 |
| 采购 | 请购、采购订单、采购收货、采购退货 |
| 库存 | 实时库存、批次与序列号、调拨、盘点、库存调整、其它出入库、来料检验 |
| 仓储 | 作业任务、波次拣货、复核装箱、移库、库位、标签打印 |
| 生产 | 物料清单、生产工单、领料退料、完工入库、成本计算 |
| 财务 | 资金（收款、付款、退款、账户转账）· 往来（核销、开票与数电发票、往来期初、信用与催收）· 总账（凭证、账簿、财务报表）· 期间（会计期间与关账、单据冲销） |
| 客户 | 线索、客户、公海、商机、合同、回款、客服工单、门户账号 |
| 审批 | 待办、已办、我的申请、抄送我的、流程设计 |
| 分析 | 业务报表、导入导出、预警中心、AI 助手、知识库 |
| 设置 | 基础资料、组织与权限、公司与参数、编码规则、自定义字段、打印模板、登录与安全、开放平台、系统运维 |

- 没有任何可见菜单的模块整体隐藏；二级菜单超过 8 项时用小标题分组（如“财务”）。
- 模块栏底部固定：帮助中心、个人设置。

### 4.3 顶栏

- 左：菜单栏收起按钮、全局搜索框（占位“搜索菜单、单号、客户、商品”，右侧显示 `Ctrl K`）。
- 右：公司切换（下拉，显示公司简称）、消息通知（未读徽标，最多 99+）、帮助、用户菜单（个人设置、修改密码、登录方式、退出）。

### 4.4 页签栏

- 最多 15 个页签，超出时关闭最早的未固定页签；工作台固定不可关闭。
- 右键菜单：刷新、关闭、关闭其他、关闭右侧、固定。
- 编辑页有未保存修改时，页签名前显示圆点，关闭前确认（沿用 `utils/unsaved.ts`）。

### 4.5 页头

```text
[←]  标题  [状态标签]                                   [次要操作] [更多 ▾] [主操作]
     副信息：客户 · 业务日期 · 制单人 · 最近更新
     （详情页）关键指标：订单金额  已发货  已签收  已收款  未结
     （有子视图时）页签：明细 | 收发记录 | 结算 | 附件 | 操作日志
```

- 列表页页头只有标题、一行说明和主操作。
- 三级以上页面在标题上方显示 12px 面包屑。

### 4.6 栅格与断点

| 断点 | 宽度 | 查询表单列数 | 描述列表列数 |
|---|---|---|---|
| xxl | ≥ 1600 | 4 | 4 |
| xl | 1200—1599 | 3 | 3 |
| lg | 992—1199 | 3 | 2 |
| md | 768—991 | 2 | 2 |
| sm | < 768 | 1 | 1 |

## 5. 页面模板

### 5.1 列表页（设计稿 02）

```text
页头：标题 + 说明                                           [导入] [新建 …]
查询卡：单号 [____]  客户 [____ ▾]  业务日期 [__ ~ __]   [查询] [重置] 展开 ⌄
表格卡：
  卡头  全部 128 | 草稿 3 | 待审核 12 | 已审核 80 | 已关闭 33      ⟳  ⇕  ⚙  ⤓
  批量条（勾选后）：已选 3 项  [批量审核] [批量打印] [导出所选]        取消选择
  表格  ☐ 单号  客户  业务日期  状态  履约  结算  金额  操作（右侧固定）
  分页  共 128 条                         每页 20 条 ▾   ‹ 1 2 3 … 7 ›
```

- 查询条件写入地址栏，刷新、从工作台跳转都能还原（沿用现有实现）。
- 单号可点击进入详情；行操作最多 2 个文字按钮，其余收进“更多”。
- 金额、数量、比例列右对齐（表头同样右对齐）；状态列用标签。
- 勾选列、单号列、操作列固定；表头吸顶。

### 5.2 编辑页（设计稿 03）

```text
页头：← 新建销售订单   草稿                                  [取消] [保存草稿]
表单卡「基础信息」：客户*  业务日期*  交货日期  销售员  仓库  价格口径（4 列）
表单卡「收货信息」（可折叠）
明细卡「商品明细」 共 3 行                     [批量粘贴] [从历史订单复制] [+ 添加行]
  # │ 商品*          │ 仓库 │ 单位 │ 数量* │ 单价   │ 折扣 │ 税率 │ 金额     │ 可用 │ ⋯
  合计                                    │  15   │        │      │      │ 1,725.00 │
表单卡「费用与备注」
底部固定操作栏：商品 1,725.00  优惠 −20.00  税额 196.15  合计 ¥1,705.00     [保存] [提交审核]
```

- 明细单元格默认无边框，悬停显示浅边框，聚焦显示主色边框；行高 36px。
- 键盘：`Enter` / `Tab` 下一格，`Shift+Tab` 上一格，`↑ ↓` 换行，最后一行 `Enter` 新增行，`Ctrl+Delete` 删除当前行；支持从 Excel 粘贴多行（商品编码、数量、单价）。
- 金额只显示服务端试算结果；试算中显示骨架占位。
- 校验错误：单元格红框 + 悬停说明；底部操作栏显示“3 处需要修改”，点击定位到第一处。

### 5.3 详情页（设计稿 04）

```text
页头：← SO-C01-202611-000123  [待审核]               [问 AI] [打印] [更多 ▾] [审核通过]
      客户 华东商贸 · 业务日期 2026-11-17 · 制单 李娜 · 更新 11-17 19:38
      订单金额 1,705.00 │ 已发货 60% │ 已签收 40% │ 已收款 0.00 │ 未结 1,705.00
步骤条：提交 ✓ — 审核 ● — 发货 — 签收 — 结清
┌───────────── 主区（16 栅格）──────────────┐┌── 右侧（8 栅格）──┐
│ 页签：明细 | 收发记录 | 结算 | 附件 3 | 操作日志 ││ 审批进度（时间线） │
│                                           ││ 关联单据            │
└───────────────────────────────────────────┘└───────────────────┘
```

- 操作按钮完全由 `allowedActions` 决定；危险操作（作废、冲销）放在“更多”里并二次确认。
- 屏宽 < 1200px 时右侧栏移到主区下方。

### 5.4 审批中心（设计稿 05）

左侧待办列表（类型图标、标题、发起人、金额、已等待时长），右侧预览单据摘要、明细和审批轨迹，底部固定“同意 / 驳回 / 转办 / 更多”。可多选后批量同意（只对同一流程且没有字段权限限制的待办开放）。

### 5.5 主从资料（设计稿 06）

左侧树或列表（部门、商品分类、库区），宽 280px，可拖动调整，支持搜索和“含下级”；右侧表格或表单。

### 5.6 工作台（设计稿 01）

问候与待办数 → 快捷入口（最多 8 个，可配置）→ 4 张指标卡（同比、环比、迷你趋势）→ 待办列表卡（按类型页签，0 项灰显）+ 右侧公告与最近访问 → 近 12 个月趋势图。

### 5.7 结果页、空状态、异常页

- 结果页：图标 + 标题 + 说明 + 主操作（查看单据）+ 次操作（继续新建）。
- 空状态：48px 线性图标 + 一句原因 + 一个操作（“新建销售订单”“清除筛选”）。
- 401 / 403 / 404 / 503 沿用现有文案，统一使用结果页模板，不显示菜单。

### 5.8 登录页

左侧 40% 品牌区（产品名、一句话定位、纯色或细纹理背景），右侧登录卡（企业编码、账号、密码；扫码、验证码、单点登录用页签切换），底部版本号。

## 6. 组件规范

### 6.1 按钮

| 类型 | 用途 | 规则 |
|---|---|---|
| 主按钮 | 区域内最重要的一个操作 | 每个区域最多一个，放最右 |
| 次按钮（描边） | 其他操作 | — |
| 文字按钮 | 表格行操作、卡片头操作 | 主色文字 |
| 危险按钮 | 作废、删除、冲销 | 描边，文字 `#CB2634`，必须二次确认 |
| 图标按钮 | 工具栏 | 必须有 `aria-label` 和悬停提示 |

文案用动词短语（“提交审核”“确认到账”），不用“确定”；按钮间距 8px。

### 6.2 查询表单

- 标签在左、右对齐，宽 80px（长标签 96px），输入框填满剩余宽度。
- 默认一行 + 操作按钮，超出的条件收进“展开”，展开状态按页面记忆。
- 日期范围用一个范围选择器，提供“今天 / 本周 / 本月 / 上月 / 本年”快捷项。
- 回车即查询；“重置”恢复默认条件，不清空状态页签。

### 6.3 表格

- 卡头左侧状态页签或标题，右侧工具栏：刷新、密度、列设置（显示、顺序、固定，按用户保存）、导出。
- 表头 `--erp-fill-1` 底、14px / 500、文字 `--erp-text-3`；行分隔 `--erp-divider`；悬停行 `--erp-fill-1`；选中行 `--erp-primary-1`。
- 长文本单行省略，悬停显示完整内容；次要信息用 12px 辅助色放在同一单元格第二行。
- 合计行固定在表格底部，`--erp-fill-1` 底、字重 500。

### 6.4 状态标签

浅底 + 文字色 + 2px 圆角，高 22px。单据状态与语义固定对应：

| 语义 | 颜色 | 示例 |
|---|---|---|
| 草稿 / 未开始 | 中性 | 草稿、未发货、未结算 |
| 进行中 / 待处理 | 信息 | 待审核、部分发货、审批中 |
| 需要注意 | 警告 | 签收超期、超信用额度、临期 |
| 完成 | 成功 | 已审核、已签收、已结清 |
| 终止 / 异常 | 危险 | 已驳回、已作废、过账失败 |
| 已关闭 / 已取消 | 中性 | 已关闭、已取消 |

履约、结算、售后三个维度在详情页页头用数字和百分比表达，不再各加一个标签，避免一行出现太多颜色（沿用 1.0 规范）。

### 6.5 描述列表

标签宽 96px、`--erp-text-3`；值 `--erp-text-1`；按断点 2—4 列。

### 6.6 弹窗与抽屉

| 场景 | 组件 | 宽度 |
|---|---|---|
| 低风险确认 | 气泡确认 | — |
| 不可撤销操作 | 确认弹窗，写明后果 | 420px |
| 简单表单（≤ 6 个字段） | 弹窗 | 520px |
| 复杂表单、详情预览 | 右侧抽屉 | 640px / 880px |
| 多步骤流程 | 页面 + 步骤条 | — |

操作按钮放底部右侧；关闭前有未保存内容时确认。

### 6.7 反馈与加载

- 操作成功：顶部居中消息，2 秒消失；后台任务完成、审批到达：右上角通知，6 秒消失。
- 表单校验错误显示在字段下方；接口错误显示服务端中文文案 + 可复制的请求编号。
- 首次加载用骨架屏；刷新、翻页在表格上方显示 2px 进度条并保留旧数据；按钮提交中显示加载图标并禁用。

### 6.8 图表

- ECharts 主题：分类色依次 `#165DFF`、`#14C9C9`、`#F7BA1E`、`#722ED1`、`#F77234`、`#3491FA`；坐标轴和网格线 `--erp-border-1`；字号 12px。
- 每张图必须有标题、单位和数据截止时间；无数据显示空状态，不画空坐标轴。

## 7. 数字、时间与文案

- 金额千分位、两位小数；单价、成本最多八位小数并去掉尾随 0（沿用 `format.ts`）；报表和余额中的负数用 `−` 号并用危险文字色。
- 时间：列表 `MM-DD HH:mm`，跨年 `YYYY-MM-DD HH:mm`；审计到秒；打印 `YYYY-MM-DD HH:mm`；工作台用“刚刚、5 分钟前、昨天 14:20”。
- 文案：短句，说清原因和下一步；不用“您”和感叹号；不出现内部字段名和英文错误码（错误码只在请求详情中显示）。

## 8. 暗色与紧凑主题

- 令牌在 `:root` 定义，暗色在 `html.dark` 下重定义：页面 `#17171A`、卡片 `#232324`、边框 `#333335`、正文 `#F6F6F6`、次要文字 `#C5C5C5`、主色 `#3C7EFF`。
- 一期只做驾驶舱大屏暗色；管理端暗色二期，在个人设置中切换，可跟随系统。
- 紧凑主题：全局尺寸切换为 `small`（24px 控件、32px 表格行），供高频录单用户选择。

## 9. 移动端（PDA 与手机，设计稿 07）

- 组件库 wot-design-uni，主色、功能色与管理端一致，在 `erp-mobile` 的主题变量中映射。
- 触控目标最小 48px；正文 16px；扫码框置顶、56px 高；每屏只显示当前步骤需要的信息。
- 成功、失败用不同提示音和震动 + 大号图标和文字，作业时不看屏幕也能分辨。
- 底部固定满宽主按钮（48px）。
