# ERP 用户使用手册

## M19 经营驾驶舱、打印与预警（本机候选）

在「报表与数据 → 经营驾驶舱」选择统计月份，排列或隐藏当前角色有权查看的指标。各区块注明数据时间，会议室可使用大屏轮播。手动刷新每人每分钟最多两次。毛利和库存金额需成本权限，现金和总账信息需对应财务权限。

在「打印模板」按单据类型建立模板，设置纸型、方向和边距。拖拽元素并从字段面板选择允许的单据字段，选实际单据预览后保存。可将启用模板设为默认，原固定模板继续作为系统默认选项。套打背景只用于对位；批量生成的 PDF 从文件任务下载。

在「预警中心」按级别、规则及状态筛选，可打开来源对象，确认、解决或填写忽略原因。规则管理员配置阈值、调度、渠道及接收人。工作台的「未处理预警」按当前公司与授权范围进入待处理列表。

## M18 生产一期（本机候选）

在「生产 → 物料清单」选父项，维护配方、有效日期、损耗、虚拟件和替代料。先提交再审核，已审核配方变更时新建版本。输入数量预览展开用料与仓库可用量。

在「生产工单」填写计划数、领料仓和完工仓，确认后下达。销售订单行缺货时可从销售详情生成工单草稿。在工单发起领料、退料和完工入库，复核后过账。PDA 支持扫描授权仓的用料。序列号、批次或库位必填时按提示扫描；退料选择原领料行，完工可以分批登记。

期末在「生产成本」选择已结束的会计期间，归集费用、填写分摊参数、计算、核对差异，再执行过账。使用总账归集时先核对直接人工和制造费用的映射。生产成本过账后，再在会计期间关账。 [生产业务规则](业务规则.md#m18-生产库存和月末成本)

## M17 仓储作业与移动端（本机候选）

在“库存 → 上架任务”按仓库筛选并领取任务。选中一行后，扫描来源和目标库位，录入数量。按批次的商品需要扫描批次，序列号商品需要录入对应序列号。可以选择有容量的存储库位，或使用页面推荐。全部行确认后点击“完成任务”。请求超时时保留原输入并重试，系统按同一请求标识返回结果。

开启后，收货或合格退货进入收货区的可用库存会生成上架任务。已冻结库存留在原库位，按既有质检和冻结流程处置。来源单据在尚未上架时可按原流程冲销并取消待办。已发生上架移库的来源单据，当前候选版本会阻止直接冲销，由仓储和财务人员先核对库位及原单。

从「库存 → 仓储作业」选择仓库。多张发货单可按承运商、客户、截单时间或人工选择组成波次。领取后按库位顺序拣货，切到「按发货单播种」核对各单明细。整行扫齐后库存和发货占用一起转到发货位。登记短拣后，按实际数量处理来源发货单。

复核时可按多箱登记，货品、批次、实扫数量和序列号须与拣货记录一致。打开「复核装箱 → 查看整单」，可以查看及打印装箱清单。有标签打印权限时，可下载整单箱标签 PDF。标签打印页还支持商品、库位和批次标签。

移库使用库位扫码建立草稿，核对后过账。补货根据固定拣货位及上下限生成草稿。库位盘点从原盘点单分配任务，逐库位确认实盘数量及盘盈或盘亏的差异序列号，原盘点单继续执行复核和过账。任务分配与统计页可分派作业并按日期核对作业数和耗时。

手机访问 ERP 同源的 `/mobile/` 查看待办、审批或执行仓储作业。PDA 在「账户安全 → 配对仓储设备」生成一次性配对码，然后在设备输入 ERP 的 HTTPS 地址及配对码。 [移动端使用说明](../erp-mobile/移动端使用说明.md)

## M16 客户与 CRM（本机候选）

在左侧“客户关系”中登记线索、记录跟进，再转为客户。遇到已有往来单位时先核对名称和税号，确认后合并到原有资料。客户负责人可维护团队和跟进记录，公海管理员可设置回收规则及员工领取上限。切换公司后，客户画像、团队和经营统计按当前公司重新加载。

商机赢单后可以建立合同。管理员先为 CRM 合同绑定已发布的审批流程，审批通过后才能按剩余数量分批生成销售订单。生成的订单继续走原有销售审批、发货签收和收款流程。回款计划可以关联现有收款单，财务确认后才计入实际回款和业绩。“价格表”维护客户协议价、客户级别价和通用价。销售录入时按这个顺序匹配，已保存的订单保留原价。

管理员在“门户账号”中为当前公司的客户联系人开通账号，将 `/portal.html` 的入口交给客户。客户可查看本账号绑定客户的订单、发货和签收、已开具发票及应收对账，选择对账期间后可下载 PDF 并确认。密码登录默认可用，短信登录由部署人员启用并验证发送渠道。门户与内部工作台分别登录。 [部署配置](部署说明.md#m16-客户门户与-ai)

客户可提交工单，启用了在线客服的门户还可从咨询转人工。坐席打开“客服工单”处理分派、回复、解决和关闭，内部备注仅供员工查看。坐席辅助按角色展示有权查看的近期订单、发货和未结应收。回复模板可以复制，坐席核对后填写并发送。

## M11 组织、消息与运维（未发布）

销售、采购相关草稿可选择业务员，报表增加“按业务员”汇总；往来单位、联系人和送货地址增加省市区。右上角铃铛进入消息中心，工作台待办读取同一收件箱，重要公告需确认。系统管理增加字典、公告、消息模板及日志、企业微信机器人、登录日志、在线用户、参数、定时任务和API日志。

完整操作、角色授权、模板变量、订阅、强退、任务执行及部署注意事项见[M11组织消息与运维使用说明](M11组织消息与运维使用说明.md)。业务员选择不增加数据权限；短信、邮件及机器人须明确配置后启用，本机验收不会向真实收件人发送消息。

## M11 部门数据范围（未发布）

先配置当前公司的用户任职及主部门，再进入“系统管理 → 角色管理 → 权限设置”，在“部门数据范围”选择并保存。每家公司独立保存配置；切换公司后须重新加载。修改未保存时离开会提示；保存结果不明时保留原内容重试，版本冲突后重新加载。

| 选项 | 可见记录 |
| --- | --- |
| 全部部门 | 公司、仓库权限内的全部记录，包括未归属历史。未配置角色默认采用此项。 |
| 本部门 | 当前公司所有启用任职部门的记录。 |
| 本部门及下级 | 任职部门及其当前下级部门的记录。 |
| 仅本人 | 已有有效部门归属且由本人制单的记录。 |
| 自定义部门 | 选中部门的记录，不自动包含下级；未选部门时该角色不增加可见记录。 |

多个角色取并集。若用户仍有一个未配置或“全部部门”角色，其他角色的限制不会缩小其范围。部门范围始终与公司、仓库及业务操作权限取交集。部门设置不能授予公司或仓库权限。

受限用户新建单据必须具有当前公司有效主部门，并且主部门在可写范围内。归属在创建时冻结，调动人员不会搬走历史单据；冲销继承原单归属。迁移时无法确定部门的历史记录只向全部范围开放。管理员应核对历史归属后再收紧角色，不能靠修改用户任职重新分配历史。

列表、报表、打印、附件和文件下载都执行范围检查。已经生成的导出文件在撤权后可能不能下载，应按新范围重新导出。库存余额是所授权仓库的共享实物快照；“范围内单据事实”报表只反映可见来源，不能替代全仓盘存余额。受限用户看不到资金账户全公司余额。

维护范围须同时具有角色授权权限和当前公司全部部门范围。部门树和用户任职维护同样需要当前公司全部部门范围；用户角色、权限、公司范围、状态及重置口令等企业级管理要求管理员在所授权的公司均拥有全部部门范围，避免通过改角色、任职或部门树扩大自身可见范围。系统保留最后一位全范围角色管理员，避免公司无人能恢复授权。全公司关账、对账及运维操作请由具有相应操作权限的全范围管理员执行。

## M11 部门与岗位（未发布）

在“系统管理 → 部门与岗位”中，先选择顶部公司。部门页左侧展示该公司部门树，右侧展示负责人和分页成员。新建时填写编码、名称、上级、排序，可选择当前公司已有访问范围的启用用户作为负责人。编码限32位字母、数字、下划线或短横线。编辑通过详情按钮进入；调整上级或顺序请拖拽部门树并确认，移动会同时更新全部下级。最多20层、每公司1000个部门。

“岗位”页签维护企业共用的岗位定义。部门页“公司用户任职配置”，或“用户管理 → 权限设置 → 部门与岗位”，可选择用户、多个部门、一个主部门及多个岗位，保存只影响当前公司。用户必须已有该公司访问范围；部门和岗位需要启用。切换公司后重新加载该公司配置，甲公司的任职不影响乙公司。

有下级或成员的部门不能停用；岗位在任意公司仍有任职时也不能停用，请先转移或清除关联。修改未保存时离开会提示；保存期间请等待。出现版本冲突时重新加载后编辑；网络保存结果不明时可重试原请求。撤销用户公司访问范围会同时清理该公司任职和负责人引用，恢复访问后需要重新配置组织。

查看部门/成员、维护部门、查看岗位、维护岗位分别受对应权限控制。用户任职修改需要 `user:update`，Y-02启用后维护部门树或任职还需当前公司全部部门范围。组织任职不授予公司或仓库权限，业务数据同时执行前述部门范围规则。

## M10 新增操作（未发布）

有结算账户修改权限的用户，可在“结算账户”中将启用账户设为默认收款或默认付款。同一公司每种用途只有一个默认账户，新设后替换旧默认；停用时清除用途。新增收付款单自动带出对应默认账户，仍可手动修改；编辑草稿沿用原选择。

有销售或采购报表权限的用户，可在工作台查看今日、昨日、本月、本年的确认金额和近十二个月趋势。销售金额按签收确认统计，采购金额按过账收货统计，退货与冲销会按业务日期抵减。卡片只展示当前公司及仓库范围，金额最多缓存五分钟。备库模式请核对“数据截至”时间，复制延迟时稍后刷新；金额加载失败可以单独重试，待办仍可使用。

## 工作台与导航

登录后进入工作台。左侧按业务分组折叠，当前分组自动展开。点击顶栏的菜单按钮可收起或展开导航，在窄屏上会从左侧打开，按 Esc 可关闭。右上角可切换公司、修改密码和退出。

顶栏下方的工作标签可在本次打开的模块之间切换。每个模块保留上次访问的页面地址和筛选条件，切换公司时会重新建立标签。工作台卡片显示当前授权内的待办及库存提示，点击卡片可进入对应筛选列表。

销售、采购等单据列表使用状态页签，支持业务日期、往来单位、仓库及进度筛选；筛选记录在地址栏，刷新或返回仍可继续查看。销售和采购订单使用独立编辑页，可逐行编辑并查看服务端金额预览；离开未保存内容时会提示确认。行数较多时请等待服务器处理；如命令超时，先查询原命令结果，避免另开一张重复单据。审批与库存约束保持不变。

会计期间改为“期间列表＋检查结果”，选择期间后先查看阻挡单据，再执行关账；库存页提供仓库、缺货及零库存筛选，可直接打开对应 SKU 的库存台账。所有成本信息仍由成本权限控制。

基础资料在右侧编辑，联系人、单位和条码按页签切换。已经被单据引用的单位换算只读；角色权限按资源和动作选择，搜索可缩小范围。报表从一个导航入口进入，通过页面选择切换类型。文件任务可下载保留原列的错误行 CSV。文件末尾附有“错误原因”列；修正后先移除此列，保持模板列顺序，再重新导入。

页面时间按北京时间显示；打印单保留完整年月日。面向客户的销售订单和发货打印隐藏内部成本。

## 报表与导出

在报表菜单选择库存汇总、库存收发存、发出未签收、销售汇总、采购汇总、应收账龄、应付账龄、往来对账单、资金日记账或毛利。选择日期及适用筛选后查询；日期默认本月至今天，最多查询一年。库存收发存可切换流水明细，来源单据可点开查看。页面显示统计时点，后续业务变化需重新查询。

销售、采购默认按客户或供应商、商品和日期汇总，可穿透到逐单行；费用汇总的穿透仅显示对应费用来源。下载文件使用中文业务列，不含系统内部 ID 或链接；无成本权限时成本列及表头都不出现。

资金日记账按资金账户和日期查询，不提供往来单位筛选；需要按客户或供应商核对余额时使用往来对账单。

查看与导出分别授权，毛利和成本字段还需成本权限；应收、应付、往来与资金报表要求整家公司范围。点击“导出报表”后到“导入与导出”的报表导出页查看进度，完成后下载 CSV。每份最多 50000 行，超限请缩小条件；每人最多同时 3 个任务，文件生成后 24 小时有效。导出只允许本人下载，权限或范围变化后可能需要重新导出。

每次下载先获取五分钟有效链接，缺少或过期的链接不能直接下载；失效后回到任务页面重新点击下载。

## 批量导入

1. 在“导入与导出”选择商品 SKU、往来单位或库存期初，下载该类型模板，按固定列顺序填写并保存为 UTF-8 CSV；每份不超过 10000 数据行和 20MB。保留编码中的前导零，不使用科学计数法；模板本身不包含示例业务数据。
2. 商品 SKU 的 `productCode` 必须为已有商品编码，基础单位沿用商品设置；不会自动新建商品或分类。往来单位 `roles` 填 `customer`、`supplier` 或 `customer|supplier`。填写采购价须有成本权限。
3. 库存期初先选择仓库和业务日期；`skuCode` 为已有 SKU，`unitName` 为该商品已配置的单位，`qty` 为正数且最多六位小数，`totalCost` 为非负整行总成本且最多两位小数，`reason` 填期初原因。期初导入需要成本权限。
4. 选择 CSV 后点击“开始导入”，页面显示后台进度。“部分成功”表示有效行已生成，错误行没有留下半条资料；错误清单显示行号、列名和原因，可下载后核对。修正错误后另存新文件再上传。重复提交相同文件和条件会返回原任务，不重复生成期初。
5. 成功记录可点击查看资料或草稿。库存期初每个有效数据行生成一张单行草稿，仍须提交、另一人审核，再由有权限人员过账；导入完成时库存和账务尚未增加。任务和错误只向原操作人开放，账号停用、撤权或仓库范围失效会中止后台处理。
6. 文件仓或数据库暂时异常时，后台最多执行 3 次并退避等待，不会把故障当成数据错误。达到上限后，或权限恢复后，失败任务仍有未处理行时会出现“重试未完成行”。点击后从断点继续，已有资料和错误清单保持；请求超时可再次点击，页面使用原请求标识恢复结果。全部行均已有结果时不显示该按钮，错误行请修正文件重传。

## 打印与附件

销售、采购、资金、库存和开票等 17 类单据详情提供打印预览。具备查看及打印权限后打开固定 A4 版式，检查抬头、明细、合计与审批信息，再调用浏览器打印。打印沿用当前字段权限，不会因打印而显示被隐藏的成本、联系方式或完整银行账号，也不改变单据状态。

详情附件区支持 PDF、JPG/JPEG、PNG、XLSX 和 CSV，单文件不超过 20MB，每张单据最多 20 个。上传需所属单据维护权限，系统校验真实文件内容。下载通过五分钟有效链接并再次校验登录及权限；链接失效时从详情重新下载。删除附件只影响附件，业务单据保留。导入源文件和导出成品在文件任务中管理，不进入普通附件列表。

删除后附件立即不能下载，文件会在一小时后由后台回收；仍被有效附件引用的对象保留，文件仓暂时故障时后台会继续重试清理。

## 操作审计与失败事件

“操作审计”支持按动作、对象类型和编号、操作人、公司、日期与请求编号筛选。拥有完整公司范围才能查看该公司的单据快照，成本、联系方式和银行账号仍按当前权限过滤。请求编号可用于定位一次操作。

有后台事件权限和整家公司范围时，可查看当前公司的失败投递。确认故障原因已解决后重放死信；系统记录审计并按事件幂等处理。页面不提供其他公司的事件内容。

## 登录与准备

本机开发环境打开 http://127.0.0.1:5173，登录页预填企业编码 `DEMO` 和用户名 `admin`。开发默认口令从本机私有配置注入；生产页面不预填。先选择业务公司，切换公司后页面重新取数。

管理员在 **系统管理 → 登录方式设置** 开启渠道后，员工先用账号密码登录，在右上角账户菜单打开 **我的登录方式** 绑定手机号、邮箱或微信。下次输入同一企业编码，即可选择已经绑定的登录方式。渠道设置和绑定细节见[多方式登录配置](多方式登录配置.md)。

销售前，准备客户角色、商品 SKU、单位换算、公司仓库、结算账户、有效库存和业务日期所在的开放期间。管理员在角色中分别授予订单、发货签收、收款、退货退款、核销、开票权限；成本查看另需 `cost:view`，修改税率另需 `document:change_tax_rate`。

订单审批和收款确认默认要求另一名人员操作，可在公司参数中设置。退款审核始终要求审核人与申请人不同。按钮按当前状态和权限出现；有权限的人员仍须满足库存、余额、额度与期间规则。

## 下单与审批

1. 进入“销售订单”，新建并选择客户、业务日期、商品、仓库、单位、数量和优惠。含税口径默认取客户设置，单价留空时服务端按所选单位换算参考价。更换件、箱等单位后重新使用单位参考价，也可明确填写单价。
2. 页面实时展示服务端试算的商品金额、行优惠、税额和合计。草稿允许暂不指定仓库，审批前每行必须有仓库。
3. 保存后提交。当前库存不足时仍可提交，页面给出提示；待审核需求不占用库存。
4. 复核人员审批。任一行库存不足时整单失败，已尝试的预留一起回滚；成功后生成有效预留。
5. 详情查看履约、结算、售后进度和预留记录。有效期取审批后默认 30 天与交货日后默认 7 天中的较晚日期，参数可由公司设置。

待审核可撤回或驳回到草稿。已批准且无下游发货单时可撤销审批，释放预留后回到草稿。预留到期会释放库存，订单仍保留为已批准，可根据当时库存重新预留。

库存页面展示在库、预留、冻结、可用和待审核需求。可用量等于在库减预留减冻结；待审核需求帮助判断潜在竞争，不参与可用量计算。

## 关闭、取消与变更

关闭剩余数量必须填写原因，数量使用基础单位，不能超过尚未发货及待发占用后的剩余量。关闭释放对应预留，关闭数量不能恢复。

没有已发和待发数量的已批准订单可以取消，取消释放预留。关联的已确认收款仍保留为客户资金，退回款项需要单独走退款申请。

已批准订单从“提交变更”修改。减少数量、改仓库、改交期或备注可直接生效；增加数量、加行、改价格税率或优惠需重新审批，批准前原版本继续有效，不能新建该订单的发货单。变更不能更换客户、公司或含税口径，不能改已发货行的价格，数量不能低于已发、待发及已关闭部分。待发占用的行改仓前先作废对应待发货单。新仓库存不足会回滚原仓释放和整次变更。

## 发货、签收与差异

新建发货单选择同一客户、同一仓库的订单行，可合并多张订单。保存草稿不占用数量，提交后占用可发量。已提交可作废，作废释放占用。

过账减少在库与预留，成本转到“发出商品”，此时不产生销售应收。客户实际签收后登记签收日期和每一行签收量，数量可以为零但不能超过发出量。签收日期不早于发货、不晚于今天，且所在期间必须开放。

签收按原订单价格、优惠与税率快照确认应收、税额和销售成本；买方费用第一次签收时整笔确认。已经确认的关联订单预收按规则自动核销。客户自提在过账时同时全数签收。

少签的数量在签收时恢复订单可发量。差异分别处理为“拒收退回”或“运输损失”：退回按原出库成本入原仓冻结待检，损失从发出商品结转。处理差异不改变已确认应收，原预留不自动恢复。补发需要当时有足够可用库存。“仅签收超期”筛选发货超过默认 7 天仍未签收的记录。

## 收款与核销

收款登记填写客户、结算账户、金额和业务日期，可关联订单。保存、提交均未增加账户余额；复核人员确认到账后才形成资金与客户未清项。关联订单的预收可在签收时自动核销，未关联或未分配部分留待手工核销。

核销工作台选择同一客户、同一币种的借方应收和贷方收款或退货信用额，填写金额后保存。不能超过双方剩余额度。撤销核销填写原因，恢复双方额度并保留历史记录。

## 销售退货与退款

退货必须选择原已签收发货行、退回仓库、单位、数量和质检结果。提交占用可退量，作废释放占用，过账确认退货信用额并按原成本入库。质检“待检”或“不合格”进入冻结量，“合格”进入可用库存。

退款选择客户、原收款、付出账户、金额与原因，可指定退货信用额等贷方未清项。提交同时占用客户可退余额和原收款可退额度；审核人复核后进入待退款。财务实际退款后填写支付日期和银行流水号，登记已退款才扣减账户余额。驳回回到草稿释放额度，待退款可取消释放额度。账户余额不足、原收款额度不足或重复占用均无法登记成功。

当前退款为财务手工登记，不直接向银行或支付渠道发起转账。

## 开票登记

开票选择已确认的正向销售应收，录入发票号、日期、金额、税额及各应收分配金额。分配合计须等于发票金额，各笔累计开票金额不能超过原应收。可分次开票，也可将一张发票关联多笔同客户应收。

开票只记录关联关系、累计开票额与税额分差，不再产生应收、收入或收款。作废登记释放开票额度。税务系统税额与单据逐行税额有分币差异时只记录差额，不回改原业务金额。系统当前不接税控开票。

## 超时与版本冲突

页面显示“结果确认中”时，点击“查询结果”。查询使用最初的请求标识，成功后刷新单据；确认尚无已提交结果时可用原请求重试，避免重复业务效果。变更审批也保留自己的原请求标识和变更版本。

提示版本冲突表示其他人已经修改单据，关闭并刷新后核对新内容。资料停用、期间关闭、库存或资金额度不足时，按提示处理原因后重新发起操作。采购、付款、期初、调拨、盘点、冲销和期间命令同样使用原请求恢复；实盘数量录入属于带版本的修改，超时先关闭刷新核对。税控开票和附件管理仍按后续里程碑实施。

## 期初录入

开始正式业务前，先开启业务日期所属期间。管理员分别授予库存期初、往来与资金期初的创建、修改、审核、过账权限。所有期初单必须由制单人以外的人员审核，审核后再过账；保存和审核本身不改变库存、往来或账户余额。

在“库存调整”新建库存调整单，调整类型选择“期初”，再填写仓库、日期、原因、商品、单位、数量和整行总成本。同一商品在一张单中只录一行，可使用件、箱等有效换算单位；换算到基础单位超过允许精度时会报错，请修正数量或换算，不会自动截断。提交后由另一人审核，过账才增加库存和成本。原库存期初入口自 0.6.0 起整合到该页面。

“往来与资金期初”选择类型和借贷方向，金额填写正数：

| 类型与方向 | 含义 | 必填对象 |
|---|---|---|
| 资金期初，借方 D | 银行或现金账户的现有余额 | 结算账户 |
| 客户往来，借方 D | 客户尚欠我方的金额 | 客户 |
| 客户往来，贷方 C | 已收客户预收款或客户信用余额 | 客户 |
| 供应商往来，贷方 C | 我方尚欠供应商的金额 | 供应商 |
| 供应商往来，借方 D | 已付供应商预付款或供应商信用余额 | 供应商 |

往来期初保存后直接交另一人审核，再过账。客户和供应商期初进入各自未清项，可在对应核销工作台分配；资金期初只增加所选账户余额。已过账期初不能直接修改或作废，正式录入前先核对日期、数量、总成本及余额。

## 请购与采购订单

1. 在“请购管理”新建请购单，填写日期、商品、单位、数量和需求日期。申请人由系统记录为当前用户。提交后由有权限的复核人员批准。
2. 在“采购订单”选择供应商、日期和明细。请购来源可选；选择已批准请购行时保留其商品与录入单位，可用数量提示使用基础单位。采购草稿保存即占用请购可转数量，其他采购单只能使用剩余量；修改、删除草稿或取消会释放相应数量。
3. 填写收货仓库、数量、单价、行优惠、整单优惠和费用。金额与税额由服务端试算；单价留空可使用有权查看的采购参考价，修改单位后重新取对应单位价格。审批前每行必须指定收货仓库。
4. 提交后由复核人员批准。公司超收容差此时冻结到订单上，例如 10 件、5% 容差可收 10.5 件；以后修改公司参数不会扩大这张订单的上限。采购审批不预留或增加库存。

详情显示每行“可收上限 / 已收”的基础数量，收货选行时提示剩余可收量，关闭时提示可关闭量。待审核可撤回或驳回。无下游收货时可撤销审批；已有待收或已收数量时不能取消。取消采购订单不会撤回已经确认的预付款，财务应单独核销或登记供应商退款。

关闭剩余填写原因和基础单位数量，不能超过服务端显示的可关闭量，关闭后不能恢复。已批准订单从“提交变更”修改，增加数量、加行、改价、税率、优惠或费用需要重新审批；批准前原有效版本保留。已收或待收的行不能修改商品、单位、价格、税率或改变分摊后的单位净额；待收行调整这些内容或仓库前，先作废对应收货单。关闭请购后不能再建立新的转单关联，已有采购草稿可以保留或减少原关联量。

## 采购收货与退货

“采购收货”选择同一供应商、同一仓库的可收采购行，可合并多张订单。按来源提示的单位填写数量，系统换算后校验基础单位上限。保存草稿不占数量，提交占用可收量，作废释放；过账才入库、确认应付、税额与移动加权成本。不能靠前端修改金额改变原采购快照。

收货成本按本次过账时的公司纳税人身份处理，系统保存含税成本口径，后改公司参数不重算原收货。关联订单的已确认预付会在本次应付确认时自动核销，未分配部分保留。历史日期补录仍按实际过账顺序更新成本，不回改已过账出库成本。

收货草稿保存后，如果采购变更修改了来源商品或单位换算快照，提交会提示来源变化。重新编辑草稿并核对来源后再提交，失败提交不会占用可收量。

“采购退货”选择同一供应商、同一仓库的原已过账收货行，按来源提示的单位填写数量和原因。提交占用原收货可退量，作废释放；过账扣库存，按原收货金额、税额、成本及税身份快照生成应付信用额，累计分批处理分币尾差。当前库存不足时不能过账；移动加权成本与原退货成本的差额由系统记录，不能手工调整退货单价。退货信用额可核销欠款，或与供应商实际退款核销。

## 付款、供应商退款与应付核销

“付款登记”选择供应商付款或其他支出。供应商付款选择供应商、付出账户、金额和日期，可关联同一供应商的采购订单作为预付；其他支出改选有效支出项目。保存和提交不扣账户余额，确认付款才扣资金并记账；默认由另一位人员确认，账户余额不足会整单失败。

订单关联预付在后续收货确认应付时自动核销；后付、未关联或未分配金额在核销工作台切换“供应商应付”后手工分配。选择同一供应商的借方付款或退货信用额，与贷方应付或供应商退款，金额不能超过双方剩余额度。撤销核销填写原因，恢复额度并保留记录。即使同一单位同时是客户与供应商，应收与应付也不能相互核销。

在销售或采购订单详情页，“已核销收款”或“已核销付款”显示这张订单实际分得的资金。比如一笔 190 元付款分别核销了 50 元期初应付和 140 元订单应付，订单上显示 140 元。“应收未清”或“应付未清”显示已确认往来的剩余金额，尚未签收或收货的订单金额不计入。撤销核销后，对应金额随账本更新。有仓库或部门限制时，页头提示金额仅覆盖当前可见范围。

供应商实际退款到账后，进入“收款登记”选择“供应商退款”，填写供应商、收款账户、金额、日期和银行流水号，提交后确认到账。确认才增加资金，并生成可与采购退货信用额核销的应付贷方未清项。付款和退款均是财务手工登记实际结果，系统不直接向银行发出指令。

## 账户转账

“账户转账”选择不同的转出、转入账户，填写本金、手续费及日期。提交后由复核人员确认，转出账户扣本金加手续费，转入账户只增加本金；手续费单独记入转账手续费。转出余额不足会整体失败，不会只增加一边余额。确认前可退回草稿修改，确认后不能重复执行；转账只登记实际发生的资金划转。

## 库存调整

“库存调整”统一处理六种业务，调整类型在创建后不能修改。填写原因、仓库、日期和商品单位数量，提交后由另一名操作人审核，再过账。草稿、待审核和已批准状态均不改变库存；驳回后按原因修改，未过账可作废。

| 类型 | 过账结果 | 成本录入 |
|---|---|---|
| 期初 | 增加期初库存，记期初权益 | 填整行总成本，可为 0 |
| 其他入库 | 增加库存，记库存调整 | 填整行总成本，可为 0 |
| 其他出库 | 减少可用库存 | 按当时移动加权成本计算 |
| 冻结 | 增加冻结量、减少可用量，在库总数不变 | 不填写成本 |
| 解冻 | 减少冻结量、恢复可用量，在库总数不变 | 不填写成本 |
| 报废 | 减少已经冻结的在库量与成本 | 按当时移动加权成本计算 |

出库不能占用其他订单的预留或冻结量；解冻不能超过当前冻结量，报废从冻结量扣减。数量或余额不足时整单失败，不会只过账部分明细。已过账调整不能直接编辑或作废，需要更正时按“单据冲销”处理。

## 库存调拨

1. 在“库存调拨”新建调拨单，选择同一公司的不同调出、调入仓库，填写业务日期、商品、录入单位和数量。操作人须同时具有两仓的数据范围。
2. 提交后点击“确认调出”，核对本次业务日期。调出扣减来源仓可用库存并形成在途，目标仓尚未增加库存；已调出不能作废。
3. 到货后点击“登记调入”，逐行填写本次实收的**基础数量**。分批到货时取消“本次为最后一批，未收部分转为差异待处理”，剩余部分继续在途；需要一次收完时可用“全部调入”。
4. 最后一批勾选上述选项，未收到的部分转入“调入差异待处理”。可以实收填 0，表示该行全部少收。再点击“处理调拨差异”，选择“退回调出仓”或“确认运输损失”，填写原因；每行一次处理该行全部待处理差异。

本次业务日期不能早于原单或已有调拨记录，且必须属于开放期间。调入和差异都沿用原调出成本，最后一笔包含剩余分币。系统重启后从原单继续处理在途，不要重新创建一张调拨单。只有实际调入的货物才成为目标仓库存。

## 库存盘点

本期采用流水水位方式，盘点期间允许继续收发货。在“库存盘点”选择仓库、业务日期和要盘点的商品，保存后点击“开始盘点”。系统记录开始时点的账面数量和水位；“录入实盘”须完整填写每行的基础单位数量，允许填 0。

实盘数应对应**开始盘点的快照时点**。若实物清点发生在随后时点，应先依据中间收发货还原该快照时点数量，再录入。系统过账只把“实盘数减快照账面数”的差额加到当前库存，期间发生的出入库会保留，不会把当前余额直接覆盖成实盘数。

实录完成后提交，由另一名操作人审批后过账；驳回会回到盘点中，核对后可重新完整录入。盘盈优先使用过账时移动加权成本或历史入库价；从未入库且没有历史价格的商品，须由有相应操作权限的人员填写盘盈单价后提交审核。盘亏按过账时移动加权成本计算，可用库存不足时失败，先处理占用或核对差异原因。

## 单据冲销

“单据冲销”用于更正录入错误，当前支持发货、销售退货、采购收货、采购退货、收款、付款、账户转账和库存调整八类来源。申请人既要有冲销权限，也要能查看原单及其公司、仓库范围。选择原单类型后按单号查找原单，填写开放期间内的冲销日期和原因；审核人必须与申请人不同，批准后再过账。

有下游退货、有效核销、退款占用或开票登记时，系统列出依赖并拒绝申请或过账。先处理相应下游：撤销可撤的业务核销、作废开票登记、处理或冲销下游业务，再回到原单申请。冲销前还会重新检查依赖和当前库存、资金，不能凭审批绕过余额限制。

冲销保留原单、原流水、原往来及凭证，再写入反向记录，原单标为已冲销；不会删除历史。发货冲销会回退订单履约进度，但不会恢复已消费的预留，继续发货前先重新预留。由冲销自动生成的抵销核销不能单独撤销。已关闭原期间的单据应选择当前开放期间冲销，原关闭期间不回改；原履约费用撤回后，新履约单可按规则重新确认费用。已冲销的原应收及冲销抵销应收不能开票，也不会出现在开票来源候选中。

## 关闭与重新打开会计期间

在“会计期间”按行点击“关账预检查”，检查未过账单据、待确认资金、库存对账、资金往来对账和成本尾差五项。任意一项未通过均不能关账；阻挡单据会返回具体单号明细，每类最多 50 条，处理相关单据或差异后重新检查。调拨在途、盘点待处理、已审核未过账调整和冲销等，也要先处理完成。

所有五项通过后点击“关账”并确认。系统会先同步待汇总凭证，再取得期间屏障复核最新事实，检查通过才关闭；并发产生新凭证时可能提示重新执行，刷新核对后使用原请求结果恢复流程。相关单据提交、期初及退款审核也要验证原业务期间，不能在关闭完成后继续提交到旧期间。

关账及重新打开要求相应权限和**整家公司数据范围**，只有单仓范围时不能执行。期间须按时间顺序关闭；需要补录时，仅能“重新打开”最近一个已关闭期间，并填写原因。关闭、重开及操作人均保留审计记录。
