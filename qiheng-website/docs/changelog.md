## 1.0.0（2026-11-18）

- 官网用 Vue 3 + TypeScript + Vite 实现，vite-ssg 预渲染成静态页，可直接部署到 GitHub Pages。
- 页面：中文首页、英文首页、AI 能力、快速开始、在线演示跳转、404。
- 导航：产品大菜单、开发者与资源下拉、悬停背景块、首页滚动高亮、滚动收紧与阅读进度、1200px 以下分组抽屉、中英文切换，支持键盘操作。
- 在线演示由构建变量 `VITE_DEMO_URL` 控制：未配置时显示“筹备中”；配置后跳转页倒计时 3 秒进入，减少动态效果时不自动跳转。
- 动效：首屏逐行出现、浮动卡片、技术栈跑马灯、滚动入场、流程光圈、AI 流程流光、描边高光、数字滚动、截图自动轮播、吉祥物探头与眨眼；离开视口暂停循环动画，系统开启“减少动态效果”时全部关闭。
- 每页输出标题、描述、规范地址和分享卡片，中英文首页互相声明 `hreflang`，构建时生成站点地图和 `404.html`。
- 新增 GitHub Pages 发布工作流 `.github/workflows/site.yaml`：`main` 上官网有改动时自动检查、构建并发布，拉取请求只检查和构建。
- 单元测试 22 项，覆盖演示地址校验、工具函数、入场动效、中英文内容一致性与站内链接、关键组件。
