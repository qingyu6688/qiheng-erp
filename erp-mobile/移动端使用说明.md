# 柒衡 ERP 仓储移动端

移动端复用 ERP 的公司、仓库、部门与操作权限。工作台为各角色展示可用的仓储作业和待办审批。Android 设备配对后使用 Bearer 令牌，H5 使用站点 Cookie 与 CSRF。

## 本机构建

在 `erp-mobile` 目录使用 Node.js 24.x 和 npm。

```powershell
npm ci
npm run lint
npm run type-check
npm test
npm run build:h5
npm run build:app
```

H5 静态入口在 `dist/build/h5`，发布至同一 ERP HTTPS 站点的 `/mobile/`。保留 `/api/v1/` 的既有代理。开发时可通过 `ERP_API_ORIGIN` 改变 Vite 的 API 代理目标，再执行 `npm run dev:h5`。

H5 和 App 资源均包含 `third-party-licenses`，以依赖包和版本保存原有许可、NOTICE 与依赖清单，发布时随产物保留。

Android 的 App 资源在 `dist/build/app`，通过 HBuilderX 导入。签名 APK 需要在 HBuilderX 配置 DCloud AppID、Android 签名及发布渠道后制作。标签 PDF 保存在 App 私有目录，由设备的 PDF 阅读应用打开，可通过阅读应用的打印入口使用打印机。 [uni-app CLI 发行说明](https://uniapp.dcloud.net.cn/worktile/CLI.html)

## 登录与扫码

- H5 打开 `/mobile/`，沿用同源 ERP 会话。无会话时可用账号密码登录，以及输入已绑定的验证码或恢复码。首次绑定验证器、变更密码或企业单点登录在管理端完成后，返回移动端。
- PDA 在已登录的管理端生成一次性设备配对码。App 输入 ERP 的 HTTPS 源地址和配对码。令牌只存放在原生 App 沙盒中，账号被强制下线后需重新配对。
- 扫码枪使用键盘模拟模式和回车后缀。进入作业行后焦点切到库位输入，再扫描目标、批次或序列号。App 可调相机。H5 需在允许摄像头的安全上下文使用相机，扫码内容在浏览器本地解码。 [平台扫码能力](https://uniapp.dcloud.net.cn/api/system/barcode.html)
- 上架、拣货会在当前步骤核对任务里的来源库位和指定批次。拣货还会核对发货库位。扫错后会显示原因并清空当前扫码框，可以直接重扫。上架允许换目标库位，提交时由服务端核实该库位属于当前仓库且可用。批次号区分大小写；打印标签使用 `L:库位编码` 或 `B:商品编码|批次号`，也可以直接扫描库位编码或批次号。

## 作业入口

- 采购收货可扫码选择待收货采购行、新建或编辑草稿，再按授权提交和过账。
- 「生产领料」从已下达工单进入。选择领料仓，扫描原物料或已冻结的替代料，再扫描商品批次、库位和序列号。保存草稿后按授权提交和过账，需发起人指定审批人的流程可以从管理端提交。
- 上架、拣货支持扫码选行、扫码确认库位及序列号。支持分批确认，剩余量按原小数精度计算。
- 波次页面按库位顺序展示发货明细，复核装箱可以按多个箱号分配数量与序列号。
- 移库可建立单据后过账，补货处理待执行任务。库位盘点显示开始盘点的北京时间。录入该时点的实盘总量，期间入库要扣除，期间出库要加回，序列号只填差额。
- 可扫码查库存、生成 PDF 标签，或查看待办单据摘要并同意、驳回。

网络异常时保留现场输入。同一版本、同一操作输入再次提交使用原幂等键。ERP 返回成功后同步任务状态。退出或切换公司会清空当前公司的工作界面与在途读取结果。
